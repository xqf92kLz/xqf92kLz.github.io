    2-1 Binary Logic and Gates（二进制逻辑与逻辑门）¶

    • Binary Logic（二进制逻辑）

      • 二进制变量（Binary Variables）仅取 0 和 1 两个值，对应 True/False、On/Off、Yes/No 等实际含义。
      • 三个基本逻辑运算（Basic Logical Operations）：
        • AND（与）：符号为“·”或“×”，表达式 \(Z=X·Y\)（\(Z=X\times Y\)），仅当 \(X\) 和 \(Y\) 均为 \(1\) 时 \(Z=1\)。
        • OR（或）：符号为“+”，表达式 \(Z=X+Y\)，\(X\) 或 \(Y\) 为 \(1\) 时 \(Z=1\)。
        • NOT（非）：符号为上划线（\(\overline{X}\)）、单引号（\(X'\)）或波浪号（\(\sim X\)），表达式 \(Z=\overline{X}\)，输入与输出相反。
      • 注意布尔代数（Boolean Algebra）与普通代数（Ordinary Algebra）的区别：如布尔代数中 \(1+1=1\)（1 OR 1=1），而非普通代数的 \(1+1=2\)。

    • Logic Gates（逻辑门）

      • 定义：实现逻辑运算的电子电路（Electronic Circuits），输入输出为二进制信号（Binary Signals），对应高低电压范围（High/Low Voltage Ranges）。

      • 图形符号（Graphic Symbols）、真值表（Truth Tables）和时序波形图（Timing Diagrams）。

      • 逻辑函数的四种描述形式：真值表（Truth Table）、布尔方程（Equation）、逻辑图（Logic Diagram）、波形图（Waveform）。

      • 分类：

        • 基本逻辑门（Basic Logic Gates）：AND Gate、OR Gate、NOT Gate（Inverter）。

        • 通用逻辑门（Universal Logic Gate）：NAND Gate（与非门，表达式 \(F=\overline{X·Y}\)），NOR Gate（或非门，表达式 \(F=\overline{X+Y}\)）。

          特性：NAND 门或 NOR 门可单独实现 AND、OR、NOT 所有运算，无需其他类型门。

        • Other Logic Gates：

          • XOR Gate（异或门）：表达式 \(F=X\oplus Y=X\overline{Y}+\overline{X}Y\)，输入不同时输出 \(1\)。
          • XNOR Gate（同或门）：表达式 \(F=\overline{X\oplus Y}=XY+\overline{X}\overline{Y}\)，输入相同时输出 \(1\)。

      • 门的实现演进（Implementation Evolution）：早期为继电器（Relays）、真空管（Vacuum Tubes），现代采用晶体管（Transistors，如 BJT）构成。

    • HDL Representations of Gates（门的 HDL 表示）

      • Verilog：提供内置门原语（Gate Primitives），如 and (F, X, Y);、nand (F, X, Y);，通过端口列表指定输入输出（输出在前，输入在后）。
      • VHDL：无内置门原语，通过逻辑运算符（Logic Operators）建模，如 F <= X and Y;、F <= X nand Y;。

    2-2 Boolean Algebra（布尔代数）¶

    • Basic Identities of Boolean Algebra（布尔代数基本恒等式）

      • 单变量恒等式（Single-Variable Identities）：
        • \(X+0=X\)、\(X·1=X\)；\(X+1=1\)、\(X·0=0\)
        • \(X+X=X\)、\(X·X=X\)；\(X+\overline{X}=1\)、\(X·\overline{X}=0\)；\(\overline{\overline{X}}=X\)
      • 运算律（Laws）：
        • 交换律（Commutative Laws）：\(X+Y=Y+X\)、\(XY=YX\)
        • 结合律（Associative Laws）：\((X+Y)+Z=X+(Y+Z)\)、\((XY)Z=X(YZ)\)
        • 分配律（Distributive Laws）：\(X(Y+Z)=XY+XZ\)、\(X+YZ=(X+Y)(X+Z)\)（对偶分配律，普通代数无此性质）
        • 德摩根定律（De Morgan's Laws）：\(\overline{X+Y}=\overline{X}·\overline{Y}\)、\(\overline{XY}=\overline{X}+\overline{Y}\)，是求函数补集的核心工具。
      • 对偶性（Duality）：将表达式中 AND（·）与 OR（+）互换、0 与 1 互换，得到对偶式（Dual Expression），恒等式成对出现（如 \(X+0=X\) 的对偶式为 \(X·1=X\)）。需要在恰当的加括号保持运算顺序不变。

    • Algebraic Manipulation（代数运算）

      • 核心目标：利用恒等式化简逻辑函数，减少项数（Terms）和文字数（Literals），降低电路复杂度。

      • 常用定理（Useful Theorems）：

        • 吸收定理（Absorption Theorem）：\(X+XY=X\)、\(X(X+Y)=X\)
        • 合并定理（Combining Theorem）：\(XY+X\overline{Y}=X\)、\((X+Y)(X+\overline{Y})=X\)

        • 共识定理（Consensus Theorem）：\(XY+\overline{X}Z+YZ=XY+\overline{X}Z\)（冗余项 \(YZ\) 可删除）

          证明

          \(\begin{aligned}XY + \overline{X}Z + YZ &= XY + \overline{X}Z + 1 \cdot YZ\\&= XY + \overline{X}Z + (X + \overline{X}) \cdot YZ\\&= XY + \overline{X}Z + XYZ + \overline{X}YZ\\&= (XY + XYZ) + (\overline{X}Z + \overline{X}YZ)\\&= XY(1 + Z) + \overline{X}Z(1 + Y)\\&= XY + \overline{X}Z\end{aligned}\)

      • 示例：将 \(\overline{X}YZ+\overline{X}Y\overline{Z}+XZ\) 化简为 \(\overline{X}Y+XZ\)。

    • Complement of a Function（函数的补集）

      • 代数方法（Algebraic Method）：反复应用德摩根定律。
      • 对偶法（Duality Method）：先求函数的对偶式，再取反每个文字（Literal），快速得到补集。
        • 示例：\(F_1=\overline{X}Y\overline{Z}+\overline{X}\overline{Y}Z\)，对偶式为 \((\overline{X}+Y+\overline{Z})(\overline{X}+\overline{Y}+Z)\)，取反文字得\(\overline{F_1}=(X+\overline{Y}+Z)(X+Y+\overline{Z})\)。

    • Advanced Boolean Theorems（进阶定理）

      • 对偶定理（Duality Theorem）：若布尔方程 \(F=G\) 成立，则其对偶式 \(F'=G'\) 也成立。
      • 代入定理（Substitution Theorem）：将布尔方程中的变量替换为任意逻辑函数，方程仍成立。
      • 补余定理（Complementary Theorem）：\(A·\overline{A}=0\)、\(A+\overline{A}=1\)；反之，若 \(A·B=0\) 且 \(A+B=1\)，则 \(B=\overline{A}\)。可用于证明德摩根定律（如证明 \(\overline{X+Y}=\overline X\cdot \overline Y\)，只需证明 \(X+Y+\overline X\cdot\overline Y=1\)，\((X+Y)\cdot(\overline X\cdot\overline Y)=0\)）。
    Tip

    常用布尔代数定理

    • 最小化（Minimization）：\(X\cdot Y+\overline{X}\cdot Y=Y\)；\((X+Y)(\overline{X}+Y)=Y\)
    • 吸收（Absorption）：\(X+X\cdot Y=X\)；\(X\cdot (X+Y)=X\)
    • 简化（Simplification）：\(X+\overline{X}\cdot Y=X+Y\)；\(X\cdot (\overline{X}+Y)=X\cdot Y\)
    • 共识（Consensus）：\(X\cdot Y+\overline{X}\cdot Z+Y\cdot Z=X\cdot Y+\overline{X}\cdot Z\)；\((X+Y)(\overline{X}+Z)(Y+Z)=(X+Y)(\overline{X}+Z)\)
    • 德摩根定律（DeMorgan’s Laws）：\(\overline{X+Y}=\overline{X}\cdot \overline{Y}\)；\(\overline{X\cdot Y}=\overline{X}+\overline{Y}\)

    2-3 Standard Forms（标准形式）¶

    • Minterms and Maxterms（最小项与最大项）
      • 最小项（Minterm，记为 \(m_i\)）：
        • 定义：\(n\) 个变量的乘积项（Product Term），每个变量以原变量（\(X\)）或反变量（\(\overline{X}\)）形式出现一次，仅在一组输入组合下为 \(1\)，共 \(2^n\) 个。
        • 示例：3变量最小项\(\overline{X}\overline{Y}\overline{Z}\)对应\(m_0\)（输入000时为1）、\(\overline{X}\overline{Y}Z\)对应\(m_1\)（输入001时为1）。
      • 最大项（Maxterm，记为\(M_i\)）：
        • 定义：n个变量的和项（Sum Term），每个变量以原变量或反变量形式出现一次，仅在一组输入组合下为0，共\(2^n\)个。
        • 示例：3变量最大项\(X+Y+Z\)对应\(M_0\)（输入000时为0）、\(X+Y+\overline{Z}\)对应\(M_1\)（输入001时为0）。
      • 核心关系：同一下标i的最小项与最大项互补，即\(M_i=\overline{m_i}\)、\(m_i=\overline{M_i}\)。
    • Sum of Products（积之和形式）
      • 定义：由若干最小项逻辑相加（OR）构成，是函数的标准“与-或”形式（Standard SOP Form），具有唯一性。
      • 表示方法：如\(F(X,Y,Z)=m_0+m_2+m_5+m_7\)，缩写为\(F(X,Y,Z)=\sum m(0,2,5,7)\)。
      • 转换：从真值表中提取函数为1的输入组合，对应最小项相加。
    • Product of Sums（和之积形式）
      • 定义：由若干最大项逻辑相乘（AND）构成，是函数的标准“或-与”形式（Standard POS Form），具有唯一性。
      • 表示方法：如\(F(X,Y,Z)=M_1·M_3·M_4·M_6\)，缩写为\(F(X,Y,Z)=\prod M(1,3,4,6)\)。
      • 转换：从真值表中提取函数为0的输入组合，对应最大项相乘；或由积之和形式求补后转换。

    2-4 Two-Level Circuit Optimization（两电平电路优化）¶

    核心结论¶

    两电平电路（与-或/或-与结构）是逻辑电路的基础形式，通过卡诺图（Karnaugh Map, K-Map）可直观合并相邻最小项/最大项，减少文字数和门数，实现电路成本优化（Cost Optimization）。

    关键内容¶

    • Cost Criteria（成本准则）
      • 文字成本（Literal Cost）：表达式中文字的总出现次数（如\(XY+\overline{X}Z\)的文字成本为4）。
      • 门输入成本（Gate-Input Cost）：所有门的输入端口总数（含内部互联和外部输入），更贴近实际电路的晶体管和布线成本（如\(XY+\overline{X}Z\)需2个2输入AND门+1个2输入OR门，门输入成本为2+2+2=6）。
    • Map Structures（卡诺图结构）
      • 本质：真值表的图形化表示，方格（Squares）对应最小项，相邻方格（含边界相邻）对应相邻最小项（仅差1个变量）。
      • 不同变量卡诺图：
        • 2变量（2-Variable）：4个方格，行/列按格雷码（Gray Code）排列（00,01,11,10）。
        • 3变量（3-Variable）：8个方格，列按00,01,11,10排列，支持左右边界相邻（如\(m_0\)与\(m_2\)相邻）。
        • 4变量（4-Variable）：16个方格，行/列均按格雷码排列，支持上下、左右边界相邻（可视为环形结构）。
    • Map Manipulation（卡诺图操作）
      • 化简步骤（Simplification Steps）：
        1. 填入函数值：将真值表或表达式中的1、0、无关项（X）填入对应方格。
        2. 识别最大相邻矩形：矩形方格数为\(2^m\)（m=0,1,...,n），优先选择规模大的矩形（减少文字数）。
        3. 覆盖所有1：确保所有填1的方格被至少一个矩形覆盖，且矩形数量最少（减少门数）。
        4. 提取乘积项：每个矩形对应一个乘积项，变量在矩形内取值不变则保留（原变量/反变量），取值变化则删除。
      • 示例：3变量函数\(F(X,Y,Z)=\sum m(0,1,2,3,4,5)\)，通过卡诺图合并得到化简式\(F=\overline{A}+\overline{B}\)（文字成本2，门输入成本2+2=4）。

    2-5 Map Manipulation（卡诺图进阶操作）¶

    核心结论¶

    通过质蕴涵项分析、和之积形式优化及无关项利用，可进一步提升卡诺图化简效果，得到更优的两电平电路设计。

    关键内容¶

    • Prime Implicants（质蕴涵项）
      • 定义：不能再合并更多相邻方格的乘积项（最大规模的相邻矩形），是化简的基础单元。
      • 分类：
        • 必要质蕴涵项（Essential Prime Implicants）：包含至少一个“唯一1”（仅被该质蕴涵项覆盖的1），必须纳入化简结果（否则无法覆盖对应1）。
        • 非必要质蕴涵项（Nonessential Prime Implicants）：无唯一1覆盖，需选择最少项覆盖剩余1，可灵活取舍。
      • 示例：函数\(F(W,X,Y,Z)=\sum m(0,1,2,4,5,10,11,13,15)\)，必要质蕴涵项为\(\overline{A}\overline{C}\)，非必要质蕴涵项包括\(ABD\)、\(A\overline{B}C\)等。
    • Product-of-Sums Optimization（和之积形式优化）
      • 核心思路：合并卡诺图中的0，得到\(\overline{F}\)的积之和形式，再应用德摩根定律转换为\(F\)的和之积形式。
      • 适用场景：当函数中0的数量少于1时，化简效率更高。
      • 示例：\(F(A,B,C,D)=\sum m(0,1,2,5,8,9,10)\)，合并0得到\(\overline{F}=AB+CD+B\overline{D}\)，转换后\(F=(\overline{A}+\overline{B})(\overline{C}+\overline{D})(\overline{B}+D)\)。
    • Don’t-Care Conditions（无关项处理）
      • 定义：函数未指定值的输入组合（记为X），实际中不会出现或不关心其输出，可灵活视为1或0辅助化简。
      • 应用原则：视为1以扩大相邻矩形规模，视为0不影响覆盖，优先选择利于化简的取值。
      • 示例：\(F(A,B,C,D)=\sum m(1,3,7,11,15)+d(0,2,5)\)，将X视为1后，化简为\(F=CD+\overline{A}\overline{B}\)或\(F=CD+\overline{A}D\)。

    2-6 Exclusive-OR Operator and Gates（异或运算符与门）¶

    核心结论¶

    异或（XOR）和同或（XNOR）是特殊的逻辑运算，多变量异或对应奇函数（Odd Function），在奇偶校验、数据比较等场景广泛应用，其性质简化了特定逻辑电路的设计。

    关键内容¶

    • XOR/XNOR 定义与性质
      • 异或（XOR，符号\(\oplus\)）：
        • 表达式：\(X\oplus Y=X\overline{Y}+\overline{X}Y\)
        • 性质：\(X\oplus 0=X\)、\(X\oplus 1=\overline{X}\)、\(X\oplus X=0\)、\(X\oplus\overline{X}=1\)，满足交换律和结合律。
      • 同或（XNOR）：
        • 表达式：\(\overline{X\oplus Y}=XY+\overline{X}\overline{Y}\)（与XOR互补）
        • 性质：\(X\oplus Y=\overline{X\oplus\overline{Y}}\)、\(X\oplus Y=Y\oplus X\)。
    • Multiple-Variable XOR（多变量异或）
      • 定义：n变量异或（奇函数，Odd Function），当输入中1的个数为奇数时输出1，偶数时输出0。
      • 表达式：3变量异或\(X\oplus Y\oplus Z=\overline{X}\overline{Y}Z+\overline{X}Y\overline{Z}+X\overline{Y}\overline{Z}+XYZ\)。
      • 实现：通过两输入XOR门级联（如3变量异或=（X\(\oplus\)Y）\(\oplus\)Z），输出为奇函数；级联XNOR门得到偶函数（Even Function）。
    • 应用场景：奇偶校验（Parity Check）、数据比较（如XOR门可检测两输入是否不同）、加法器（半加器核心组件）。

    2-7 Gate Propagation Delay（门传播延迟）¶

    核心结论¶

    门传播延迟（Propagation Delay）是电路时序性能的关键指标，决定电路运行速度，需考虑延迟类型、负载影响及建模方法，是时序约束设计的基础。

    关键内容¶

    • Delay Parameters（延迟参数）
      • \(t_{PHL}\)：输出从高电平（High, H）变为低电平（Low, L）的延迟时间。
      • \(t_{PLH}\)：输出从低电平（Low, L）变为高电平（High, H）的延迟时间。
      • \(t_{pd}\)：门延迟（Propagation Delay），取\(t_{PHL}\)和\(t_{PLH}\)的最大值，是衡量门速度的核心指标（如TTL门\(t_{pd}\)约10ns，CMOS门\(t_{pd}\)约1ns）。
    • Delay Models（延迟模型）
      • 传输延迟（Transport Delay）：输入变化后，输出延迟固定时间响应，不考虑短脉冲（即使输入脉冲宽度小于延迟，输出仍会响应）。
      • 惯性延迟（Inertial Delay）：若输入变化间隔小于“抑制时间”（Rejection Time），输出不响应，避免毛刺（Glitch）产生，更贴近实际门特性。
    • Factors Affecting Delay（影响延迟的因素）
      • 门的固有延迟（Intrinsic Delay）：由器件工艺（如CMOS/BJT）和门类型决定。
      • 扇出（Fan-Out）：门输出驱动的负载个数（标准负载，Standard Load, SL），负载越多，延迟越大。
      • 示例：4输入NAND门延迟公式\(t_{pd}=0.07+0.021×SL\)，若驱动3个标准负载（0.8+1.0+1.0），则\(t_{pd}=0.07+0.021×2.8=0.129ns\)。

    2-8 HDLs Overview（硬件描述语言概述）¶

    核心结论¶

    硬件描述语言（HDL）是复杂数字电路设计、仿真与综合的核心工具，支持从结构到行为的多层级建模，适配大规模数字系统设计需求，主流语言为VHDL和Verilog。

    关键内容¶

    • HDL 核心作用（Core Functions）
      • 替代原理图（Schematic Replacement）：描述电路结构（组件互联）和行为（输入输出关系），比原理图更高效、易维护，支持复杂电路设计。
      • 仿真验证（Simulation & Verification）：通过HDL模型进行功能仿真（Functional Simulation）和时序仿真（Timing Simulation），确保设计符合需求。
      • 逻辑综合（Logic Synthesis）：将寄存器传输级（RTL）HDL描述自动转换为优化的门级网表（Gate-Level Netlist），满足面积（Area）、速度（Speed）约束。
    • 主流HDL对比（Mainstream HDLs）
      • VHDL：强类型语言（Strongly Typed），标准化程度高，适用于复杂系统建模，常用于军工、航空航天领域。
      • Verilog：语法简洁，贴近硬件，易用性强，广泛用于ASIC和FPGA设计，工业界应用更普遍。
    • Design Flow（设计流程）
      1. 描述（Description）：编写HDL代码（结构/数据流/行为/RTL级）。
      2. 分析与Elaboration：编译器检查语法语义，生成扁平化的仿真模型（Flattened Simulation Model）。
      3. 仿真（Simulation）：通过测试平台（Testbench）施加输入激励，验证输出正确性。
      4. 综合（Synthesis）：将RTL级描述转换为门级网表，结合工艺库（Technology Library）优化。
      5. 物理设计（Physical Design）：布局（Placement）、布线（Routing），生成芯片版图（Layout）。

    2-9 HDL Representations-VHDL¶

    核心结论¶

    VHDL通过“实体（Entity）-结构体（Architecture）”结构描述电路，支持结构（Structural）、数据流（Dataflow）、行为（Behavioral）三种建模方式，适配从底层门级到高层功能级的设计需求。

    关键内容¶

    • Basic Structure（基本结构）
      • 实体（Entity）：定义电路的输入输出端口（Ports），是电路的“接口说明书”。
        • 端口模式（Port Modes）：in（输入）、out（输出）、inout（双向）、buffer（缓冲输出）。
        • 数据类型（Data Types）：std_logic（单bit）、std_logic_vector（多bit向量，如std_logic_vector(1 downto 0)表示2bit向量）。
        • 示例：两比特大于比较器实体定义： 
          entity comparator_greater_than is
    port (A, B: in std_logic_vector(1 downto 0);
                A_greater_than_B: out std_logic);
end comparator_greater_than;
      • 结构体（Architecture）：描述电路内部逻辑，依附于实体存在，一个实体可对应多个结构体。
    • Modeling Styles（建模风格）
      • 结构描述（Structural Modeling）：通过组件（Component）实例化和端口映射（Port Map）描述组件互联，对应原理图。
        • 步骤：声明组件→声明内部信号（Signal）→实例化组件并映射端口。
      • 数据流描述（Dataflow Modeling）：通过并发赋值语句（<=）和逻辑运算符，描述数据流向，对应布尔方程。
        • 示例：\(A_greater_than_B <= (A(1) and not B(1)) or (A(1) and A(0) and not B(0)) or (A(0) and not B(1) and not B(0));\)
      • 行为描述（Behavioral Modeling）：通过条件语句（when-else/with-select）描述电路功能，不依赖具体结构，抽象层级最高。
        • 示例：\(A_greater_than_B <= '1' when (A > B) else '0';\)
    • Testbench（测试平台）
      • 定义：无输入输出端口的VHDL模块，用于验证待测试模块（DUT, Device Under Test）的功能。
      • 核心组件：DUT实例化、激励信号（reg类型，用于产生输入）、观测信号（wire类型，用于观测输出）。
      • 激励产生：通过进程（Process）施加输入序列，如时钟信号、数据信号。

    2-10 HDL Representations-Verilog¶

    核心结论¶

    Verilog通过“模块（Module）”结构描述电路，语法灵活简洁，支持门原语（Gate Primitives）、连续赋值（Continuous Assignment）、条件运算符（Conditional Operator）等建模方式，适配快速原型设计和工业界大规模应用。

    关键内容¶

    • Basic Structure（基本结构）
      • 模块（Module）：Verilog的基本设计单元，包含端口定义、内部信号声明和逻辑描述，是电路的完整描述。
        • 端口定义：input（输入）、output（输出）、inout（双向）。
        • 内部信号：wire（线网，用于连接组件）、reg（寄存器，用于时序逻辑或测试平台激励）。
        • 示例：两比特大于比较器模块定义： 
          module comparator_greater_than(input [1:0] A, B,
                                                            output reg A_greater_than_B);
    // 逻辑描述部分
endmodule
    • Modeling Styles（建模风格）
      • 结构描述（Structural Modeling）：使用内置门原语（and/or/not/nand等）实例化，描述组件互联。
        • 示例：and u1(and0_out, A[1], ~B[1]);（2输入AND门实例化）。
      • 数据流描述（Dataflow Modeling）：通过连续赋值语句（assign）和位运算符（&/|/~^等），对应布尔方程。
        • 示例：assign and0_out = A[1] & ~B[1];
      • 行为描述（Behavioral Modeling）：通过条件运算符（?:）、always块描述电路功能，支持更高抽象层级。
        • 示例：assign A_greater_than_B = (A > B) ? 1'b1 : 1'b0;
    • Testbench（测试平台）
      • 定义：无端口的Verilog模块，实例化DUT并施加激励。
      • 激励产生：通过initial块（仅执行一次）或always块（循环执行）产生输入信号，如： 
        module comparator_tb;
    reg [1:0] A, B;
    wire A_greater_than_B;
    // DUT实例化
    comparator_greater_than uut(A, B, A_greater_than_B);
    // 激励产生
    initial begin
        A = 2'b10; B = 2'b00; #10;
        B = 2'b01; #10;
        B = 2'b10; #10;
        B = 2'b11; #10;
    end
endmodule

    2-11 Chapter Summary（章节总结）¶

    核心结论¶

    本章系统覆盖组合逻辑电路设计的基础理论、优化方法、时序特性及HDL建模技术，是数字电路设计的核心基础，关键知识点可归纳为“逻辑基础-化简优化-时序约束-HDL建模”四大模块。

    关键知识点总结（Key Knowledge Summary）¶

    1. 逻辑基础（Logic Foundations）：二进制逻辑、基本逻辑运算、逻辑门类型及通用门特性。
    2. 布尔代数（Boolean Algebra）：基本恒等式、运算律、函数补集求解、代数化简方法。
    3. 标准形式（Standard Forms）：最小项/最大项定义、积之和/和之积形式转换。
    4. 两电平优化（Two-Level Optimization）：卡诺图结构与化简步骤、质蕴涵项分析、无关项处理。
    5. 特殊运算（Special Operations）：XOR/XNOR的性质、多变量异或（奇函数）实现。
    6. 时序特性（Timing Characteristics）：门延迟参数、延迟模型、扇出对延迟的影响。
    7. HDL建模（HDL Modeling）：VHDL/Verilog的基本结构、建模风格、测试平台设计。
