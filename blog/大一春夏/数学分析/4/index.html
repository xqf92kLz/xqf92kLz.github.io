    Fourier 级数

    2026-03-242026-04-02

    知识点¶

    概念¶

    • 定义：形如

      \(\displaystyle\frac{1}{2}a_0 + \sum_{n=1}^{\infty}(a_n \cos nx + b_n \sin nx)\)

      的函数项级数称为三角级数，其中 \(a_n, b_n\) 均为常数。

    • 上述级数中的每一项都是以 \(2\pi\) 为周期的周期函数。

      如果函数 \(f\) 可以表示成上述三角级数，\(f\) 也必是以 \(2\pi\) 为周期。

      问题：

      1. 对于以 \(2\pi\) 为周期的函数 \(f\)，当它满足什么条件时，可以展开成三角级数？
      2. 当函数 \(f\) 可以展开成三角级数，相应系数如何计算？

    基本三角函数系¶

    • 正交函数系：

      设 \(S=\{\varphi_0(x),\varphi_1(x),\varphi_2(x),\cdots\}\) 是 \([a,b]\) 上定义的实函数集合。如果 \(S\) 中每个函数都在 \([a,b]\) 上可积，且满足

      \(\displaystyle\int_a^b\varphi_n(x)\varphi_m(x)dx=\begin{cases}0,&n\neq m\\\lambda_n>0,&n=m\end{cases}\)

      则称 \(S\) 是 \([a,b]\) 上的正交函数系。

    • 基本三角函数系及其正交性：

      在 \([-\pi, \pi]\) 上的基本三角函数系为：

      \(1,\ \cos x,\ \sin x,\ \cos 2x,\ \sin 2x,\ \cdots,\ \cos nx,\ \sin nx,\ \cdots\)

      此函数系构成 \([-\pi,\pi]\) 上的正交函数系，满足如下正交关系：

      \(\int_{-\pi}^{\pi}\cos nxdx = \int_{-\pi}^{\pi}\sin nxdx = 0 \quad (n \geq 1)\)

      \(\int_{-\pi}^{\pi}\sin mx \cos nxdx = 0 \quad (m,n \geq 1)\)

      \(\int_{-\pi}^{\pi}\cos mx \cos nxdx = \int_{-\pi}^{\pi}\sin mx \sin nxdx = 0 \quad (m \neq n)\)

      \(\int_{-\pi}^{\pi}\cos^2 nxdx = \int_{-\pi}^{\pi}\sin^2 nxdx = \pi \quad (n = 1,2,\ldots)\)

      \(\int_{-\pi}^{\pi} 1 \cdot dx = 2\pi\)

    • Fourier 系数的推导

      设 \(f\) 是以 \(2\pi\) 为周期的函数，假设它可以表示成

      $ f(x) = \frac{1}{2}a_0 + \sum_{n=1}^{\infty}(a_n \cos nx + b_n \sin nx),\quad x\in\mathbb{R} $

      假设该级数在 \([-\pi,\pi]\) 上一致收敛于 \(f\)，则可逐项积分，利用正交性确定系数。

      推导 \(a_0\)： 两边在 \([-\pi,\pi]\) 上积分，利用 \(\int_{-\pi}^{\pi}\cos nxdx = \int_{-\pi}^{\pi}\sin nxdx = 0\)：

      \(\displaystyle \int_{-\pi}^{\pi} f(x)dx = \frac{1}{2}a_0 \cdot 2\pi + 0 = \pi a_0 \quad \Rightarrow \quad \boxed{a_0 = \frac{1}{\pi}\int_{-\pi}^{\pi}f(x)dx}\)

      推导 \(a_k\)（\(k \geq 1\)）： 两边乘以 \(\cos kx\) 后在 \([-\pi,\pi]\) 积分，利用正交性，右边只有含 \(a_k\) 的项非零：

      \(\displaystyle \int_{-\pi}^{\pi}f(x)\cos kxdx = a_k\int_{-\pi}^{\pi}\cos^2 kxdx = a_k\pi \quad \Rightarrow \quad \boxed{a_n = \frac{1}{\pi}\int_{-\pi}^{\pi}f(x)\cos nxdx,\quad n=1,2,\ldots}\)

      注意 \(a_0\) 的公式与 \(a_n\)（\(n\geq 1\)）统一写成 \(n=0\) 时也成立。

      推导 \(b_k\)（\(k \geq 1\)）： 两边乘以 \(\sin kx\) 后在 \([-\pi,\pi]\) 积分：

      \(\displaystyle \int_{-\pi}^{\pi}f(x)\sin kxdx = b_k\int_{-\pi}^{\pi}\sin^2 kxdx = b_k\pi \quad \Rightarrow \quad \boxed{b_n = \frac{1}{\pi}\int_{-\pi}^{\pi}f(x)\sin nxdx,\quad n=1,2,\ldots}\)

    Fourier 系数¶

    • 定义：设 \(f\) 是 \(2\pi\) 周期函数，且在 \([-\pi,\pi]\) 上可积或绝对可积。则称

      $\displaystyle a_n = \frac{1}{\pi}\int_{-\pi}^{\pi}f(x)\cos nxdx,\quad n=0,1,2,\ldots $

      $\displaystyle b_n = \frac{1}{\pi}\int_{-\pi}^{\pi}f(x)\sin nxdx,\quad n=1,2,\ldots $

      为 \(f\) 的 Fourier 系数，并称三角级数

      $\displaystyle \frac{1}{2}a_0 + \sum_{n=1}^{\infty}(a_n\cos nx + b_n\sin nx) $

      为 \(f\) 的 Fourier 级数，记作

      $\displaystyle f(x) \sim \frac{1}{2}a_0 + \sum_{n=1}^{\infty}(a_n\cos nx + b_n\sin nx) $

      注意：符号"\(\sim\)"表示左边函数对应此 Fourier 级数，不代表级数一定收敛到 \(f(x)\)，收敛性需另行讨论。

      例

      例题

      设

      \(f(x) = \begin{cases} x, & -\pi < x < \pi \\ 0, & x = \pm\pi \end{cases}\)

      以 \(2\pi\) 为周期，求 \(f(x)\) 的 Fourier 级数。

      计算 \(a_0\)： \(f(x)=x\) 是奇函数，在对称区间 \([-\pi,\pi]\) 上积分为零：

      $\displaystyle a_0 = \frac{1}{\pi}\int_{-\pi}^{\pi} xdx = 0 $

      计算 \(a_n\)（\(n\geq 1\)）： 奇函数 \(\times\) 偶函数（\(\cos nx\)）= 奇函数，在对称区间积分为零：

      $\displaystyle a_n = \frac{1}{\pi}\int_{-\pi}^{\pi} x\cos nxdx = 0 $

      计算 \(b_n\)（\(n\geq 1\)）： 奇函数 \(\times\) 奇函数（\(\sin nx\)）= 偶函数，利用偶函数性质：

      \(\displaystyle b_n = \frac{1}{\pi}\int_{-\pi}^{\pi} x\sin nxdx = \frac{2}{\pi}\int_0^{\pi} x\sin nxdx\)

      分部积分

      \(\displaystyle = \frac{2}{\pi}\int_0^{\pi} xd\left(-\frac{\cos nx}{n}\right) = \frac{2}{\pi}\left[-\frac{x\cos nx}{n}\bigg|_0^{\pi} + \int_0^{\pi}\frac{\cos nx}{n}dx\right]\)

      \(\displaystyle = \frac{2}{\pi}\left[-\frac{\pi\cos n\pi}{n} + \frac{\sin nx}{n^2}\bigg|_0^{\pi}\right] = \frac{2}{\pi}\cdot\left(-\frac{\pi(-1)^n}{n}\right) = \frac{2(-1)^{n-1}}{n}\)

      故 \(f(x)\) 的 Fourier 级数为：

      \(\boxed{f(x) \sim 2\sum_{n=1}^{\infty}\frac{(-1)^{n-1}}{n}\sin nx = 2\left(\sin x - \frac{\sin 2x}{2} + \frac{\sin 3x}{3} - \cdots\right)}\)

    Fourier 系数的基本性质¶

    在讨论 Fourier 级数的收敛性之前，先看看 Flourier 系数的性质。

    假设 \(f\) 的 Fourier 系数为 \(a_n(f),b_n(f)\)。

    命题：

    • \(\displaystyle\max\{|a_n(f)|,|b_n(f)|\}\leq \dfrac 1 \pi\int_{-\pi}^\pi |f(x)|dx\)

    • 线性性：\(\alpha f + \beta g\) 的 Fourier 系数为

      \(a_n(\alpha f+\beta g)=\alpha a_n(f)+\beta a_n(g),\quad b_n(\alpha f+\beta g)=\alpha b_n(f)+\beta b_n(g)\)

    • 奇偶性：

      • 若 \(f(x)\) 为奇函数，则 \(a_n(f)=0\)（Fourier 级数只含正弦项）；
      • 若 \(f(x)\) 为偶函数，则 \(b_n(f)=0\)（Fourier 级数只含余弦项）。

    • 平移性质：令 \(f_h(x)=f(x+h)\)，则 \(a_0(f_h)=a_0(f)\)，\(a_n(f_h)=a_n(f)\cos nh+b_n(f)\sin nh\)，\(b_n(f_h)=b_n(f)\cos nh-a_n(f)\sin nh\)

    Fourier 级数的衰减性质¶

    由函数的光滑性推断 Fourier 系数的衰减速度。

    • 引理：设 \(f(x)\) 以 \(2\pi\) 为周期，且在 \([-\pi,\pi]\) 上绝对可积，则相应的 Fourier 系数满足

      $ \lim_{n\to\infty} a_n = 0,\qquad \lim_{n\to\infty} b_n = 0 $

    • 定理（黎曼-勒贝格引理 (Riemann-Lebesgue Lemma)）：设在区间 \([a,b]\) 上 \(f(x)\) 黎曼可积（或广义绝对可积），则

      $ \displaystyle\lim_{p\to+\infty}\int_a^b f(x)\cos pxdx = 0,\qquad \lim_{p\to+\infty}\int_a^b f(x)\sin pxdx = 0$

    • 命题：设 \(f\in C(\mathbb{R})\) 以 \(2\pi\) 为周期。若 \(f\in D[-\pi,\pi]\)（可微）且 \(f'\in R[-\pi,\pi]\)（导数 Riemann 可积），则

      $ \displaystyle{a_n(f) = -\frac{b_n(f')}{n},\qquad b_n(f) = \frac{a_n(f')}{n}} $

      证明

      $\displaystyle b_n(f') = \frac{1}{\pi}\int_{-\pi}^{\pi}f'(x)\sin nxdx $

      分部积分

      \(\displaystyle = \frac{1}{\pi}\left[f(x)\sin nx\Big|_{-\pi}^{\pi} - n\int_{-\pi}^{\pi}f(x)\cos nxdx\right]\)

      由 \(f\) 的 \(2\pi\) 周期性，\(f(\pi)\sin(n\pi)=f(-\pi)\sin(-n\pi)=0\)，边界项为零：

      $\displaystyle = -\frac{n}{\pi}\int_{-\pi}^{\pi}f(x)\cos nx,dx = -n,a_n(f) $

      故 \(a_n(f) = -\dfrac{b_n(f')}{n}\)。对 \(a_n(f')\) 类似分部可得 \(b_n(f) = \dfrac{a_n(f')}{n}\)。\(\blacksquare\)

    • 命题：设 \(f\in C^{m-1}(\mathbb{R})\)，以 \(2\pi\) 为周期。若 \(f\in D^m[-\pi,\pi]\) 且 \(f^{(m)}\in R[-\pi,\pi]\)，则

      \(|a_n(f)| + |b_n(f)| \leq \dfrac{|a_n(f^{(m)})| + |b_n(f^{(m)})|}{n^m}\)

      意义：\(f\) 越光滑，Fourier 系数衰减越快，级数越容易收敛。

      由 Riemann–Lebesgue 引理，\(a_n(f^{(m)}),b_n(f^{(m)})\to 0\)，因此

      $ |a_n(f)|,|b_n(f)| = o\left(\dfrac{1}{n^m}\right) \quad (n\to\infty) $

    逐点收敛性¶

    • 考虑 Fourier 级数的部分和

      \(\displaystyle S_n(x) = \frac{a_0}{2} + \sum_{k=1}^{n}(a_k\cos kx + b_k\sin kx)\)

      \(\displaystyle =\dfrac 1 \pi\left[\dfrac 1 2\int_{-\pi}^\pi f(t)dt+\sum_{k=1}^n\int_{-\pi}^\pi f(t)(\cos kt\cos kx+\sin kt\sin kx)dt\right]\)

      \(\displaystyle =\dfrac 1 \pi\int_{-\pi}^\pi f(t)\left[\dfrac 1 2 +\sum_{k=1}^n (\cos kt\cos kx+\sin kt\sin kx)\right]dt\)

      \(\displaystyle =\dfrac 1 \pi\int_{-\pi}^\pi f(t)\left[\dfrac 1 2 +\sum_{k=1}^n \cos k(t-x)\right]\)

    • 定义（Dirichlet 核）：令

      $\displaystyle D_n(x) = \frac{1}{\pi}\left(\frac{1}{2} + \sum_{k=1}^{n}\cos kx\right) \quad \text{(Dirichlet kernel)}, $

      则

      $ \boxed{S_n(x) = \int_{-\pi}^{\pi} f(t) D_n(t-x)dt.} $

      Dirichlet 核的性质：

      • 当 \(x \neq 0\) 时（利用 \(2\sin\frac{x}{2}\cos kx = \sin(k+\tfrac{1}{2})x - \sin(k-\tfrac{1}{2})x\) 累加）：

        \(D_n(x) = \dfrac{\sin\left(n+\tfrac{1}{2}\right)x}{2\pi\sin\dfrac{x}{2}};\)

      • 当 \(x = 0\) 时：\(D_n(0) = \dfrac{1}{\pi}\left(n+\dfrac{1}{2}\right)\)；

      • \(D_n(x)\) 是偶函数、\(2\pi\) 周期函数；

      • \(\displaystyle\int_{-\pi}^{\pi} D_n(x)dx = 2\int_{0}^{\pi} D_n(x)dx = 1\).

    • 部分和的对称化表示

      \(\displaystyle S_n(x) = \int_{-\pi}^{\pi} f(x-t)D_n(t)dt\)

      \(\displaystyle =\int_{-\pi}^\pi f(x-t)D_n(t)dt\)

      利用 \(D_n\) 为偶函数，得

      \(\boxed{S_n(x) = \int_{0}^{\pi}\bigl[f(x+t)+f(x-t)\bigr]D_n(t)dt.}\)

      代入 \(D_n(t) = \dfrac{\sin(n+\frac{1}{2})t}{2\pi\sin\frac{t}{2}},\quad t\neq 0\)，得

      $ \displaystyle S_n(x) = \frac{1}{2\pi}\int_{0}^{\pi}[f(x+t)+f(x-t)]\dfrac{\sin\left(n+\tfrac{1}{2}\right)t}{\sin\tfrac{t}{2}}dt.$

    • 问题：对于给定的 \(x_0\)，当 \(f\) 满足什么条件时，它的 Fourier 级数在 \(x_0\) 处收敛？

      目标：\(S_n(x_0) \to A\)（\(n \to \infty\)）。

      利用 Dirichlet 核的性质 \(2\displaystyle\int_0^\pi D_n(t)dt = 1\)，可将

      \(\displaystyle A = A \cdot 2\int_{0}^{\pi}D_n(t)dt\)

      代入 \(S_n(x_0)-A\)：

      $\displaystyle S_n(x_0) - A = \frac{1}{2\pi}\int_{0}^{\pi}\bigl[f(x_0+t)+f(x_0-t)-2A\bigr]\frac{\sin(n+\frac{1}{2})t}{\sin\tfrac{t}{2}}dt. $

      \(\displaystyle= \frac{1}{2\pi} \int_0^\delta [f(x_0+t) + f(x_0-t) - 2A] \frac{\sin(n+\frac{1}{2})t}{\sin \frac{t}{2}} dt\)

      \(\displaystyle+ \frac{1}{2\pi} \int_\delta^\pi [f(x_0+t) + f(x_0-t) - 2A] \frac{\sin(n+\frac{1}{2})t}{\sin \frac{t}{2}} dt\)

      当 \(t \in [\delta,\pi]\) 时，\(\sin\tfrac{t}{2} \ge \sin\tfrac{\delta}{2} > 0\)，故函数

      \(\dfrac{f(x_0+t)+f(x_0-t)-2A}{2\sin\tfrac{t}{2}}\)

      在 \([\delta,\pi]\) 上 Riemann 可积（\(f\) 绝对可积即可保证）。由 Riemann–Lebesgue 引理，

      $\displaystyle \lim_{n\to\infty}\frac{1}{2\pi}\int_{\delta}^{\pi}\dfrac{f(x_0+t)+f(x_0-t)-2A}{2\sin\frac{t}{2}}\sin(n+\frac{1}{2})tdt = 0. $

    • 定理（Riemann 局部化原理）：

      假设 \(f(x)\) 以 \(2\pi\) 为周期，且在 \([-\pi, \pi]\) 上绝对可积。 则对于任意给定的 \(x_0\)，\(f\) 的 Fourier 级数在 \(x_0\) 处是否收敛，仅与 \(f\) 在 \(x_0\) 附近的性质有关，而与 \(f\) 在离 \(x_0\) 较远的点无关。

      \(f\) 的 Fourier 级数在 \(x_0\) 收敛于 \(A\) 的充要条件是：\(\exists \delta>0\)，使得

      $\displaystyle \lim_{n\to\infty}\int_{0}^{\delta}\frac{f(x_0+t)+f(x_0-t)-2A}{t}\sin\left(n+\frac{1}{2}\right)tdt = 0. $

    Dini 收敛定理¶

    • 定理（Dini）：假设 \(f(x)\) 以 \(2\pi\) 为周期，且在 \([-\pi,\pi]\) 上绝对可积。则对于任意给定的 \(x_0\)，如果存在实数 \(A\) 和 \(\delta > 0\)，使得

      $ \displaystyle\int_{0}^{\delta}\frac{|f(x_0+t)+f(x_0-t)-2A|}{t}dt < \infty, $

      则 \(f\) 的 Fourier 级数在 \(x_0\) 收敛于 \(A\)。

    • 定理（Dini）：假设 \(f(x)\) 以 \(2\pi\) 为周期，且在 \([-\pi,\pi]\) 上绝对可积。则对于任意给定的 \(x_0\)，如果 \(\delta > 0\) 使得

      1. \(f(x_0+0)\) 和 \(f(x_0-0)\) 都存在（即左右极限存在）；
      2. 积分 \(\displaystyle \int_{0}^{\delta}\frac{f(x_0+t)-f(x_0+0)}{t}dt\) 与 \(\displaystyle \int_{0}^{\delta}\frac{f(x_0-t)-f(x_0-0)}{t}dt\) 绝对收敛，

      则 \(f\) 的 Fourier 级数在 \(x_0\) 收敛于 \(A = \dfrac{f(x_0+0)+f(x_0-0)}{2}.\)

    几种连续性的定义¶

    • 定义（Dini 连续）：设 \(f\) 是在 \(x_0\) 的邻域内有定义的函数。如果存在 \(\delta>0\) 和区间 \([0,\delta]\) 上的非负连续函数 \(\varphi\)，使得

      \(|f(x_0\pm t)-f(x_0)|\le\varphi(t), \quad \forall t\in[0,\delta],\quad\) 且 $\displaystyle\int_{0}^{\delta}\frac{\varphi(t)}{t}dt<\infty, $

      则称 \(f\) 在 \(x_0\) 处 Dini 连续。

    • 定义（Hölder 连续）：如果存在 \(\delta>0\)，\(0 < \alpha \le 1\) 和 \(C>0\)，使得

      $ |f(x_0+t)-f(x_0)|\le C|t|^\alpha, \quad \forall t\in[-\delta,\delta], $

      则称 \(f\) 在 \(x_0\) 处 \(\alpha\) 阶 Hölder 连续（\(C^{0,\alpha}\)）。特别地，\(\alpha=1\) 情形称为 Lipschitz 连续。

    从强弱关系上来看：可导 \(\Rightarrow\) Lipschitz 连续 (\(\alpha=1\)) \(\Rightarrow\) \(\alpha\) 阶 Hölder 连续 (\(0<\alpha<1\)) \(\Rightarrow\) Dini 连续 \(\Rightarrow\) 普通连续。傅里叶级数在某一点能够收敛到函数值，普通连续是不够的，但只要函数在该点满足上述三种连续性中的任意一种（如 Dini 连续），即可确保傅里叶级数的完美收敛。

    Dini–Lipschitz 收敛定理¶

    • 定理（Dini–Lipschitz 1）：假设 \(f(x)\) 以 \(2\pi\) 为周期，且在 \([-\pi,\pi]\) 上绝对可积。如果 \(f\) 在 \(x_0\) 处 Dini 连续（Hölder 连续，Lipschitz 连续），那么 \(f\) 的 Fourier 级数在 \(x_0\) 收敛于 \(f(x_0)\)。

    • 定理（Dini–Lipschitz 2）：假设 \(f(x)\) 以 \(2\pi\) 为周期，且在 \([-\pi,\pi]\) 上分段 Dini 连续（分段 Hölder 连续，分段 Lipschitz 连续）。则 \(f\) 的 Fourier 级数：

      • 在连续点 \(x_0\) 处收敛于 \(f(x_0)\)；
      • 在间断点 \(x_0\) 处收敛于 \(\dfrac{1}{2}\bigl[f(x_0+0)+f(x_0-0)\bigr]\)。

    Dirichlet 收敛定理¶

    • 定义（分段可导函数）：设 \(f\) 是定义在 \([a,b]\) 上的函数。如果存在 \([a,b]\) 的分割

      $ a = t_0 < t_1 < \cdots < t_m = b, $

      使得在每个小区间 \([t_{i-1},t_i]\) 上定义的函数

      $ f_i(x) = \begin{cases} f(t_{i-1}+0), & x = t_{i-1}, \ f(x), & x \in (t_{i-1},t_i), \ f(t_i-0), & x = t_i, \end{cases} $

      都是 \([t_{i-1},t_i]\) 上的可导函数，则称 \(f\) 是分段可导函数。

    • 定理（Dirichlet）：假设 \(f(x)\) 是以 \(2\pi\) 为周期的分段可导函数，则 \(f\) 的 Fourier 级数在 \(x_0\) 收敛到 \(\dfrac 1 2 [f(x_0+0)+f(x_0-0)]\)。

    • 定理（Dirichlet-Jordan）：假设 \(f(x)\) 以 \(2\pi\) 为周期，且在 \([-\pi,\pi]\) 上绝对可积。又设 \(x_0\) 是任意一点，如果存在 \(\delta>0\)，使 \(f\) 在区间 \((x_0-\delta,x_0)\) 和 \((x_0,x_0+\delta)\) 上分别单调且有界，则 \(f\) 的 Fourier 级数在 \(x_0\) 收敛于 \(\dfrac 1 2 [f(x_0+0)+f(x_0-0)]\)。

    Fourier 级数的其他收敛性¶

    • 定理（Weierstrass 第二逼近定理）：设 \(f(x)\) 是以 \(2\pi\) 为周期的连续函数。则存在三角多项式

      $\displaystyle T_n(x) = \frac{\alpha_0}{2} + \sum_{k=1}^{n}(\alpha_k\cos kx + \beta_k\sin kx)\quad (n=1,2,\cdots), $

      使得 \(\forall\varepsilon>0\)，\(\exists N\)，\(\forall n>N\)，\(\forall x\in\mathbb{R}\)，有

      $ |f(x)-T_n(x)| < \varepsilon. $

      即连续的周期函数可以被三角多项式一致逼近。

      注意：该定理不说明 \(f\) 的 Fourier 部分和 \(S_n(x)\) 一致收敛（事实上连续函数的 Fourier 级数未必一致收敛，甚至未必逐点收敛），而是存在某组三角多项式可做到一致逼近。

      证明

      设 \(S_n(x)\) 为 \(f\) 的 Fourier 级数部分和，定义算术平均（Cesàro 和）：

      $ \sigma_n(x) = \dfrac{S_0(x)+S_1(x)+\cdots+S_n(x)}{n+1}. $

      由 \(S_n(x) = \displaystyle\int_{-\pi}^{\pi}f(x+t)D_n(t)dt\)，得

      \(\displaystyle \sigma_n(x) = \frac{1}{n+1}\int_{-\pi}^{\pi}f(x+t)\sum_{k=0}^{n}D_k(t)dt.\)

      定义 Fejér 核：

      $\displaystyle F_n(t) = \frac{1}{n+1}\sum_{k=0}^{n}D_k(t). $

      利用 Dirichlet 核求和公式，可得

      \(\displaystyle F_n(t)=\dfrac 1 {(n+1)\pi}\dfrac{\sum_{k=0}^n \sin (k+\frac 1 2)t}{2\sin \frac t 2}\)

      \(=\dfrac 1 {(n+1)\pi}\dfrac{\sum_{k=0}^n 2\sin \frac t 2 \sin (k+\frac 1 2)t}{4\sin^2 \frac t 2}\)

      \(=\dfrac 1 {(n+1)\pi}\dfrac{\sum_{k=0}^n (\cos kt-\cos(k+1)t)}{4\sin^2\frac t 2}\)

      \(=\dfrac 1 {(n+1)\pi}\dfrac{1-\cos(n+1)t}{4\sin^2\frac t 2}\)

      \(=\dfrac{1}{2\pi(n+1)}\cdot\dfrac{\sin^2\frac{(n+1)t}{2}}{\sin^2\frac{t}{2}} \quad (t\neq 0),\)

      $ F_n(0) = \dfrac{n+1}{2\pi}. $

      Fejér 核的性质：

      • \(F_n(t)\ge 0,\quad\forall t\)（非负性，这是与 Dirichlet 核的关键区别）；
      • \(\displaystyle\int_{-\pi}^{\pi}F_n(t)dt = 1\)；
      • 偶函数，周期函数。

      下面我们证明，\(f\) 的 Fourier 级数的部分和数列的算术平均数列 \(\sigma_n(x)\) 在 \([-\pi,\pi]\) 上一致收敛于 \(f(x)\)。

      $\displaystyle \sigma_n(x) = \int_{-\pi}^{\pi}f(x+t)F_n(t)dt. $

      由 \(\displaystyle\int_{-\pi}^{\pi}F_n(t)dt=1\)，有

      \(\displaystyle |\sigma_n(x)-f(x)| = \left|\int_{-\pi}^{\pi}[f(x+t)-f(x)]F_n(t)dt\right|\)

      \(\displaystyle \leq \int_{-\pi}^\pi|f(x+t)-f(x)|F_n(t)dt\)

      \(\displaystyle\leq\left(\int_{-\pi}^{-\delta}+\int_{-\delta}^\delta+\int_\delta^\pi\right)|f(x+t)-f(x)|F_n(t)dt\)

      \(=I_1+I_2+I_3\)

      对于第一项的估计，要用到 Fejer 核的性质

      \(\displaystyle I_1=\int_{-\pi}^{-\delta}|f(x+t)-f(x)|F_n(t)dt\)

      \(\displaystyle =\int_{-\pi}^{-\delta}|f(x+t)-f(x)|\dfrac{\sin^2\frac{n+1}2 t}{2\pi(n+1)\sin^2\frac t 2}dt\)

      \(\displaystyle\leq \dfrac{2M}{2\pi(n+1)}\int_{-\pi}^{-\delta}\dfrac 1 {\sin^2\frac t 2}dt\)

      \(\displaystyle \leq \dfrac{M}{(n+1)\sin^2\frac\delta 2}\to 0\)

      对于第二项的估计，主要用到一致连续函数的性质

      \(\displaystyle I_2=\int_{-\delta}^\delta|f(x+t)-f(x)|F_n(t)dt<\varepsilon\)

      对于第三项的估计，与第一项的估计同理。

      故 \(\sigma_n(x)\rightrightarrows f(x)\)。 又 \(\sigma_n(x)\) 是三角多项式，故得证。\(\blacksquare\)

      例

      例（利用 Fejér 定理的推论

      设 \(f(x)\in C(-\infty,+\infty)\) 且以 \(2\pi\) 为周期，再设 \(f(x)\) 的 Fourier 级数处处收敛。证明：\(f(x)\) 的 Fourier 级数必处处收敛于 \(f(x)\)。

      证明：

      设 \(S_n(x)\to A(x)\)（处处收敛），由 Fejér 定理，\(\sigma_n(x)\rightrightarrows f(x)\)（一致收敛到 \(f\)）。

      若 \(S_n(x)\to A(x)\)（逐点），则其算术平均 \(\sigma_n(x)\to A(x)\)（逐点）。

      由唯一性，\(A(x)=f(x)\) 处处成立。\(\blacksquare\)

    • 定义（均方收敛）：设函数 \(f(x),f_n(x)\) 在区间 \([a,b]\) 上平方可积，并且

      \(\displaystyle \lim_{n\to \infty}\int_a^b[f_n(x)-f(x)]^2dx=0\)

      则称函数列 \(\{f_n(x)\}\) 在 \([a,b]\) 上均方收敛于 \(f(x)\)。

    • 定理（Fourier 级数的最佳逼近）：假设函数 \(f(x)\) 是以 \(2\pi\) 为周期的函数，且在 \([-\pi, \pi]\) 上绝对可积且平方可积。 则对于所有阶数不大于 \(n\) 的任意三角多项式 \(T_n(x)\)，有

      \(\displaystyle \int_{-\pi}^\pi |f(x) - S_n(x)|^2 dx \le \int_{-\pi}^\pi |f(x) - T_n(x)|^2 dx,\)

      其中 \(S_n(x)\) 为 \(f\) 的 Fourier 级数的部分和。

      证明

      假设 \(f(x)\) 以 \(2\pi\) 为周期，且在 \([-\pi,\pi]\) 上绝对可积且平方可积。

      记 \(T_n(x)=\dfrac{A_0}{2}+\displaystyle\sum_{k=1}^{n}(A_k\cos kx+B_k\sin kx)\) 为任意 \(n\) 阶三角多项式，\(a_k, b_k\) 为 \(f\) 的 Fourier 系数。

      根据三角函数系的正交性

      \(\displaystyle\int_{-\pi}^{\pi}|f(x)-T_n(x)|^2dx\)

      \(\displaystyle= \int_{-\pi}^{\pi}f^2(x)dx+ \pi\frac{(A_0-a_0)^2}{2}\)

      \(\displaystyle +\pi\sum_{k=1}^{n}\bigl[(A_k-a_k)^2+(B_k-b_k)^2\bigr]-\pi\left[\frac{a_0^2}{2}+\sum_{k=1}^{n}(a_k^2+b_k^2)\right].\)

      由此可知，当 \(A_k=a_k\)，\(B_k=b_k\) 时，上式取到最小值。\(\blacksquare\)

      另外有

      \(\displaystyle \int_{-\pi}^{\pi}|f(x)-S_n(x)|^2dx = \int_{-\pi}^{\pi}f^2(x)dx - \pi\left[\frac{a_0^2}{2}+\sum_{k=1}^{n}(a_k^2+b_k^2)\right].\)

    • 定理（Fejér）：假设 \(f(x)\) 以 \(2\pi\) 为周期，且在 \([-\pi,\pi]\) 上绝对可积且平方可积。则 \(f\) 的 Fourier 级数在 \([-\pi,\pi]\) 上均方收敛于 \(f\)，即

      \(\displaystyle \lim_{n\to\infty}\int_{-\pi}^{\pi}|f(x)-S_n(x)|^2dx = 0.\)

    • 定理（Parseval）：假设 \(f(x)\) 以 \(2\pi\) 为周期，且在 \([-\pi,\pi]\) 上绝对可积且平方可积。则 \(f\) 的 Fourier 系数满足

      \(\displaystyle\frac{1}{2}a_0^2 + \sum_{n=1}^{\infty}(a_n^2+b_n^2) = \frac{1}{\pi}\int_{-\pi}^{\pi}|f(x)|^2dx.\)

      证明

      由均方收敛（Fejér 定理），

      \(\displaystyle\lim_{n\to\infty}\int_{-\pi}^{\pi}|f(x)-S_n(x)|^2dx = 0.\)

      由最佳逼近公式，

      \(\displaystyle\int_{-\pi}^{\pi}|f(x)-S_n(x)|^2dx = \int_{-\pi}^{\pi}f^2(x)dx - \pi\left[\frac{a_0^2}{2}+\sum_{k=1}^{n}(a_k^2+b_k^2)\right].\)

      令 \(n\to\infty\)，左边趋于零，故

      \(\displaystyle \pi\left[\frac{a_0^2}{2}+\sum_{k=1}^{\infty}(a_k^2+b_k^2)\right] = \int_{-\pi}^{\pi}f^2(x)dx,\)

      即得 Parseval 恒等式。\(\blacksquare\)

    • 推论（Bessel 不等式）：假设 \(f(x)\) 以 \(2\pi\) 为周期，且在 \([-\pi,\pi]\) 上绝对可积且平方可积。则 \(f\) 的 Fourier 系数满足

      \(\displaystyle \frac{1}{2}a_0^2 + \sum_{n=1}^{m}(a_n^2+b_n^2) \le \frac{1}{\pi}\int_{-\pi}^{\pi}|f(x)|^2dx, \quad\forall m.\)

    • 推论（Parseval 恒等式推广）：假设函数 \(f(x)\) 和 \(g(x)\) 都以 \(2\pi\) 为周期，且在区间 \([-\pi, \pi]\) 上绝对可积且平方可积。则 \(f(x)\) 和 \(g(x)\) 的 Fourier 系数满足

      \(\displaystyle\frac{1}{2}a_0 c_0 + \sum_{n=1}^\infty (a_n c_n + b_n d_n) = \frac{1}{\pi} \int_{-\pi}^\pi f(x)g(x) dx\)

      其中 \(a_n, b_n\) 是函数 \(f(x)\) 的 Fourier 系数；\(c_n, d_n\) 是函数 \(g(x)\) 的 Fourier 系数。

    • 推论（唯一性）：设 \(f\in C[-\pi,\pi]\)，若 \(f\) 的 Fourier 系数全为 \(0\)，则 \(f(x)=0\)。
