    函数列与函数项级数¶

    2026-03-212026-03-25

    知识点¶

    函数列的收敛¶

    • 定义：给定函数列 \(\{f_n(x)\}\)，每一项 \(f_n(x)\) 都在实数集 \(D\) 上有定义。

      固定 \(x \in D\)，就得到一个数列 \(\{f_n(x)\}\)。

      • 如果这个数列收敛，那么称 \(x\) 是函数列 \({f_n(x)}\) 的收敛点。
      • 相应地定义发散点。
      • 函数列的全体收敛点组成的集合 \(E\) 称为它的点态收敛域。

      • 极限函数定义为：\(f(x) := \lim_{n \to \infty} f_n(x), \quad x \in E\)

      • 或记为 \(f_n(x) \to f(x)\ (n \to \infty)\)。

    • 问题：函数列的连续性、可微性、可积性能否传递给极限函数？

      例

      • 考察函数列 \(f_n(x) = x^n,\ n \in \mathbb{N}\)。极限函数为 \(f(x) = \begin{cases} 0, & |x| < 1 \\ 1, & x = 1 \end{cases}\)。

        \(\Rightarrow\) 函数列中每个函数都连续，但函数列的极限不一定连续。

      • 考虑区间 \([0, 1]\) 上的函数列：\(f_n(x) = \begin{cases} 1, & n!\cdot x \in \mathbb{Z}, \\ 0, & n!\cdot x \notin \mathbb{Z} \end{cases} \quad n \in \mathbb{N}\)。收敛域为 \([0,1]\) 中的有理数集，极限函数为 Dirichlet 函数。

        \(\Rightarrow\) 函数列中每个函数都可积，但函数列的极限不一定可积。

      • 考察函数列 \(f_n(x) = \dfrac{\sin nx}{\sqrt{n}},\ n \in \mathbb{N},\ x \in \mathbb{R}\)。

        • 收敛域为 \(\mathbb{R}\)，极限函数为零。
        • \(f_n'(x) = \sqrt{n}\cos nx\)，而 \(\lim_{n\to\infty} f_n'(0) = \lim_{n\to\infty} \sqrt{n} = +\infty\)。

        \(\Rightarrow\) 函数列各项导数的极限，不一定等于函数列极限的导数。

      • 考察函数列 \(f_n(x) = n|x|(1-x^2)^n,\ n \in \mathbb{N}\)。

        • 收敛域为 \([-1, 1]\)，极限函数为零。
        • 但 \(\int_{-1}^{1} f_n(x)\,dx = 2\int_0^1 nx(1-x^2)^n\,dx = \frac{n}{n+1} \not\to 0 = \int_{-1}^{1} f(x)\,dx\)

        \(\Rightarrow\) 函数列各项积分的极限，不一定等于函数列极限的积分。

      上述例子说明，对函数列取点态极限的过程中，函数的连续性、可微性和可积性都不能保持。不能通过逐项求导和逐项积分再取极限的方法来求极限函数的导数和积分。

      问题：能否通过附加一些条件，得到函数列中每一项函数的性质传递给极限函数？

    函数列的一致收敛¶

    • 定义：设 \(E\) 是一个非空数集，\({f_n(x)}\) 是定义在 \(E\) 上的函数列，\(f(x)\) 在 \(E\) 上有定义。如果

      \(\forall \varepsilon > 0,\ \exists N > 0,\ \forall n > N,\ \forall x \in E,\ |f_n(x) - f(x)| < \varepsilon,\)

      那么称函数列 \({f_n(x)}\) 在 \(E\) 上一致收敛于 \(f(x)\)，记作

      \(f_n(x) \rightrightarrows f(x)\quad (x \in E).\)

      注：

      • 点态收敛与一致收敛的区别：

        • 点态收敛：\(\forall x \in E,\ \forall \varepsilon > 0,\ \exists N > 0,\ \forall n > N \Rightarrow |f_n(x) - f(x)| < \varepsilon\)

        • 一致收敛：\(\forall \varepsilon > 0,\ \exists N > 0,\ \forall n > N,\ \forall x \in E \Rightarrow |f_n(x) - f(x)| < \varepsilon\)

        关键区别：\(N\) 是否依赖 \(x\)。一致收敛中 \(N = N(\varepsilon)\)，与 \(x\) 无关。

      • 一致收敛可以推出点态收敛。

      • 不一致收敛的否定：\(\exists \varepsilon_0 > 0,\ \forall N > 0,\ \exists n_0 > N,\ \exists x_0 \in E,\ |f_{n_0}(x_0) - f(x_0)| \geq \varepsilon_0\)。

      • 一致收敛有几何意义：对任意 \(\varepsilon > 0\)，存在足够大的 \(N\)，使得当 \(n > N\) 时，所有 \(f_n(x)\) 的图像都被夹在 \(f(x) - \varepsilon\) 和 \(f(x) + \varepsilon\) 之间的带形区域 \([a, b]\) 中。

        不一致收敛：总存在某 \(x\) 处，\(f_n(x)\) 跑出带形区域。

    • 定理：\(f_n(x) \rightrightarrows f(x)\ (x \in E) \iff \lim_{n \to \infty} \sup_{x \in E} |f_n(x) - f(x)| = 0\)

      例

      例 1

      考察 \(f_n(x) = \dfrac{x}{1+nx^2},\ x \in \mathbb{R}\)，极限函数 \(f(x) = 0\)。

      \(\left|\dfrac{x}{1+nx^2} - 0\right| = \dfrac{|x|}{1+nx^2} = \dfrac{\sqrt{n}|x|}{1+(\sqrt{n}x)^2} \cdot \dfrac{1}{\sqrt{n}} \leq \dfrac{1}{2\sqrt{n}} \to 0\)

      （利用 \(\dfrac{t}{1+t^2} \leq \dfrac{1}{2}\)，令 \(t = \sqrt{n}\cdot|x|\)）

      \(\forall x \in \mathbb{R}\)，\(\sup_x \left|\dfrac{x}{1+nx^2}\right| = \dfrac{1}{2\sqrt{n}} \to 0\)，故一致收敛。

      例 2

      考察 \(f_n(x) = \dfrac{nx}{1+n^2x^2},\ x \in \mathbb{R}\)，极限函数 \(f(x) = 0\)。

      \(\left|\dfrac{nx}{1+n^2x^2} - 0\right| = \dfrac{n|x|}{1+n^2x^2}\)

      取 \(x_0 = \dfrac{1}{n}\)，则 \(f_n\left(\dfrac{1}{n}\right) = \dfrac{1}{2}\)。

      否定一致收敛：\(\exists \varepsilon_0 = \dfrac{1}{2}\)，\(\forall N > 0\)，取 \(n_0 > N\)，取 \(x_0 = \dfrac{1}{n_0} \in \mathbb{R}\)，使得

      \(|f_{n_0}(x_0) - 0| = \frac{1}{2} \geq \varepsilon_0\)

      故不一致收敛（\(x \in \mathbb{R}\)）。

      例 3

      考察 \(f_n(x) = x^n,\ n \in \mathbb{N}\)，极限函数 \(f(x) = \begin{cases} 0, & |x| < 1 \\ 1, & x = 1 \end{cases}\)。

      \(|x^n - 0| = |x|^n < r^n < \varepsilon \quad (\forall x \in (-r, r),\ 0 < r < 1)\)

      \(\sup_{x\in(-r,r)} |x|^n = r^n \to 0\)，故 \(\{f_n\}\) 在 \((-r, r)\)（\(0 < r < 1\)）上一致收敛于 \(0\)。

      但在 \((-1, 1)\) 上不一致收敛（\(\sup_{x \in (-1,1)}|x^n| = 1 \not\to 0\)）。

      例 4

      设 \(f(x) \in C[0,1]\)，\(f(1) = 0\)，证明：\(x^n f(x) \rightrightarrows 0\)（\(x \in [0,1]\)）。

      将 \([0,1]\) 分成两段，取 \(0 < r < 1\)：

      在 \([0, r]\) 上：

      因为 \(f \in C[0,1]\)，故 \(f\) 在 \([0,1]\) 上有界，设 \(|f(x)| \leq M\)，则

      \(|x^n f(x) - 0| = |x|^n |f(x)| \leq M r^n\)

      由于 \(r < 1\)，\(Mr^n \to 0\)，故在 \([0, r]\) 上一致收敛于 \(0\)。

      在 \([r, 1]\) 上：

      因为 \(f(1) = 0\) 且 \(f\) 在 \(x = 1\) 处连续，故 \(\forall \varepsilon > 0\)，\(\exists \delta > 0\)，当 \(|x - 1| < \delta\) 时，\(|f(x) - f(1)| = |f(x)| < \varepsilon\)。

      取 \(r = 1 - \delta\)，则 \(\forall x \in [r, 1]\)：\(|x-1| \leq 1 - r = \delta\)，故

      \(|x^n f(x)| \leq |x|^n \cdot |f(x)| \leq 1 \cdot |f(x) - f(1)| < \varepsilon\)

      故在 \([r, 1]\) 上也一致收敛于 \(0\)。

      综合两段，\(x^n f(x) \rightrightarrows 0\)（\(x \in [0,1]\)）。\(\blacksquare\)

      例 5

      设 \(f(x) \in C^1(\mathbb{R})\)，令 \(g_n(x) = n\left(f\left(x + \dfrac{1}{n}\right) - f(x)\right)\)。证明：在任意给定的闭区间 \([a, b]\) 上，\(g_n(x) \rightrightarrows f'(x)\)。

      由拉格朗日中值定理：

      \(g_n(x) = \dfrac{f\left(x+\tfrac{1}{n}\right)-f(x)}{\tfrac 1 n} = f'\left(x + \tfrac{\theta}{n}\right), \quad 0 < \theta < 1\)

      \(|g_n(x) - f'(x)| = \left|f'\left(x+\tfrac{\theta}{n}\right) - f'(x)\right|\)

      因为 \(f' \in C(\mathbb{R})\)，故 \(f'\) 在 \([a, b+1]\) 上一致连续：\(\forall \varepsilon > 0,\ \exists \delta > 0\)，当 \(\left|\tfrac{\theta}{n}\right| < \delta\) 时，

      \(|f'(x+\tfrac{\theta}{n}) - f'(x)| < \varepsilon, \quad \forall x \in [a,b]\)

      取 \(n > \dfrac{1}{\delta}\)，则 \(\tfrac{\theta}{n} < \tfrac{1}{n} < \delta\)，故

      \(|g_n(x) - f'(x)| < \varepsilon, \quad \forall x \in [a, b]\)

      即在 \([a,b]\) 上 \(g_n \rightrightarrows f'\) \(\blacksquare\)

    • 定理：

      1. 若 \(\{f_n(x)\}\) 在 \(E\) 上一致收敛于 \(f(x)\)，则对于 \(E\) 的任意非空子集 \(E_1\)，\(\{f_n(x)\}\) 也在 \(E_1\) 上一致收敛于 \(f(x)\)。
      2. 若 \(\{f_n(x)\}\) 在有限个非空集 \(E_1, E_2, \cdots, E_m\) 上都一致收敛于 \(f(x)\)，则 \(\{f_n(x)\}\) 也在 \(E = \bigcup_{k=1}^{m} E_k\) 上一致收敛于 \(f(x)\)。
      3. 如果 \(\{f_n(x)\}\)、\(\{g_n(x)\}\) 在 \(E\) 上均一致收敛，则 \(\forall \alpha, \beta \in \mathbb{R}\)，\(\{\alpha f_n(x) + \beta g_n(x)\}\) 在 \(E\) 上也一致收敛。

    • 问题：乘积的一致收敛？

      \(x^n(1-x)\) 在 \((0,1)\) 上一致收敛，\(\frac 1 {1-x}\) 在 \((0,1)\) 上一致收敛（每一项都是 \(\frac 1 {1-x}\) 的函数列），但 \(x^n\) 在 \((0,1)\) 上不一致收敛。

      若要讨论 \(f_n g_n \rightrightarrows fg\)，关键不等式为：\(|f_n g_n - fg| \leq |f_n - f||g_n| + |f| \cdot |g_n - g|\)，需要额外条件：\(g_n\) 一致有界，即 \(\boxed{|g_n(x)| \leq M \quad (\forall n,\ \forall x \in E)}\)，以及 \(f\) 有界（在有界闭区间上由连续性自动保证）。

    • 定理（柯西准则）：函数列 \(\{f_n(x)\}\) 在 \(E\) 上一致收敛的充要条件是：

      \(\forall \varepsilon > 0,\ \exists N > 0,\ \forall m > n > N,\ \forall x \in E,\quad |f_m(x) - f_n(x)| < \varepsilon.\)

    • 定理（阿贝尔连续性定理）：设 \(\{f_n(x)\}\) 在区间 \(I\) 上满足：

      1. \(f_n(x) \in C(I)\)（\(\forall n\)）；
      2. \(f_n(x)\) 在 \(I\) 上逐点收敛于 \(f(x)\)。

      则有：

      (1) 如果 \(\{f_n(x)\}\) 在某点 \(x_0 \in I\) 的附近局部一致收敛于 \(f(x)\)，则 \(f(x)\) 在 \(x_0\) 处连续。

      (2) 如果对任意有界闭区间 \([a,b] \subset I\)，\(\{f_n(x)\}\) 都在 \([a,b]\) 上一致收敛于 \(f(x)\)（即内闭一致收敛），则 \(f(x) \in C(I)\)。

      证明

      证明 (1)：在 \([a,b]\) 上，\(f_n \rightrightarrows f\) 且每个 \(f_n\) 连续，证 \(f\) 在 \(x_0 \in [a,b]\) 处连续。

      写出 \(f_n\) 连续这个已知条件：

      \(\forall n,\ f_n(x) \in C[a,b]\iff\forall n,\ \forall \varepsilon > 0,\ \exists \delta_1 > 0,\ \forall |\Delta x| < \delta_1:\quad |f_n(x+\Delta x) - f_n(x)| < \varepsilon\)

      写出一致连续这个已知条件：

      \(f_n(x) \rightrightarrows f(x)\ ([a,b]) \iff \forall \varepsilon > 0,\ \exists N_1 > 0,\ \forall n > N_1,\ \forall x \in [a,b]:\quad |f_n(x) - f(x)| < \frac{\varepsilon}{3}\)

      目标是证 \(|f(x)-f(x_0)\) 可以任意小。

      三角不等式拆分：

      \(|f(x) - f(x_0)| \leq \underbrace{|f(x) - f_n(x)|}_{<\varepsilon/3} + \underbrace{|f_n(x) - f_n(x_0)|}_{<\varepsilon/3\ (\text{取}\,|\Delta x|<\delta_1)} + \underbrace{|f_n(x_0) - f(x_0)|}_{<\varepsilon/3}\)

      取 \(n > N_1\)（固定），再由 \(f_n\) 在 \(x_0\) 连续取 \(\delta_1\)，则 \(\forall |x - x_0| < \delta_1\)：

      \(|f(x) - f(x_0)| < \varepsilon\)

      即 \(f\) 在 \(x_0\) 连续。\(\blacksquare\)

      证明 (2)：取 \(\exists\, [a,b] \subset I\) 使得 \(x_0 \in [a,b]\)，由内闭一致收敛条件知在 \([a,b]\) 上 \(f_n \rightrightarrows f\)，再由 (1) 得 \(f\) 在 \(x_0\) 处连续。\(\blacksquare\)

      推论：如果 \(\{f_n(x)\}\) 在某点 \(x_0 \in I\) 的附近局部一致收敛于 \(f(x)\)，则 \(\lim_{x \to x_0} \lim_{n \to \infty} f_n(x) = \lim_{n \to \infty} \lim_{x \to x_0} f_n(x)\)。

      证明

      左边是 \(\lim_{x \to x_0} f(x)\)，右边是 \(\lim_{n\to\infty} f_n(x_0)\)（即 \(f(x_0)\)）。两者相等就是在说 \(f\) 在 \(x_0\) 连续，即 \(\lim_{x\to x_0} f(x) = f(x_0)\)。

    • 定理（逐项可积性）：设 \({f_n(x)}\) 是定义在区间 \([a, b]\) 上的函数列，且满足：

      1. \(f_n(x) \in R[a,b]\)（每项 Riemann 可积）；
      2. \({f_n(x)}\) 在 \([a, b]\) 上一致收敛于 \(f(x)\)。

      则 \(f(x) \in R[a,b]\)，且 \(\int_a^b f(x)dx = \lim_{n\to\infty} \int_a^b f_n(x)dx\)

      即极限与积分可以交换：\(\int_a^b \lim_{n\to\infty} f_n(x)dx = \lim_{n\to\infty} \int_a^b f_n(x)dx\)

      证明

      第一步：证明 \(f \in R[a,b]\)

      • （\(f\in R[a,b]\iff \forall\varepsilon>0\)，\(\exists\, [a,b]\) 的一个分割 \(\Delta=\{x_0=a,x_1,x_2,\cdots,x_n=b\}\)，使得 \(\sum_{k=1}^n \omega_k(f)\Delta x_k<\varepsilon\)，其中第 \(k\) 个子区间的振幅 \(\omega_k(f)=\sup\limits_{x,y\in[x_{k-1},x_k]}|f(x)-f(y)|\)）

        写出已知条件：

        \(f_n(x)\in R[a,b]\iff \forall \varepsilon>0,\ \sum_{k=1}^p \omega_k(f_n)\Delta x_k<\varepsilon\)

        \(f_n(x) \rightrightarrows f(x)\ ([a,b]) \iff \forall \varepsilon > 0,\ \exists N_1 > 0,\ \forall n > N_1,\ \forall x \in [a,b]:\quad |f_n(x) - f(x)| < \varepsilon\)

        目标是用 \(f_n\) 的振幅控制 \(f\) 的振幅。

        对 \(\forall x, y \in C_k = [x_{k-1}, x_k]\)，\(n>N_1\)，三角不等式给出：

        \(|f(x) - f(y)| \leq |f(x) - f_n(x)| + |f_n(x) - f_n(y)| + |f_n(y) - f(y)|\)

        则 \(\sup_{x,y \in C_k} |f(x)-f(y)| \leq \sup_{x,y\in C_k}|f_n(x)-f_n(y)| + 2\varepsilon\)

        即得关键不等式 \(\boxed{\omega_k(f) \leq \omega_k(f_n) + 2\varepsilon}\)

        对分划 \(\Delta\) 求加权和：

        \(\sum_{k=1}^{p} \omega_k(f),\Delta x_k \leq \underbrace{\left[\sum_{k=1}^{p} \omega_k(f_n)\Delta x_k\right]}_{\text{可积故}< \varepsilon} + 2\varepsilon \sum_{k=1}^{p}\Delta x_k\)

        \(< \varepsilon + 2\varepsilon(b-a) = (2b - 2a + 1)\varepsilon\)

        由 \(\varepsilon\) 的任意性，\(f \in R[a,b]\)。\(\blacksquare\)

      第二步：证明积分值收敛

      • \(\left|\int_a^b f_n(x)dx - \int_a^b f(x)dx\right| = \left|\int_a^b \bigl(f_n(x) - f(x)\bigr)dx\right|\)

        \(\leq \int_a^b |f_n(x) - f(x)|dx \leq (b-a)\cdot\sup_{x \in [a,b]} |f_n(x) - f(x)| \to 0\)

        最后一步利用了一致收敛：\(\displaystyle\sup_{x}|f_n(x)-f(x)| \to 0\)（\(n\to\infty\)）。

        故 \(\displaystyle\lim_{n\to\infty}\int_a^b f_n(x)dx = \int_a^b f(x)dx\)。\(\blacksquare\)

    • 定理（逐项可微性）：设函数列 \(\{f_n(x)\}\) 是定义在区间 \([a, b]\) 上的可微函数列，且满足

      1. \(\{f_n(x)\}\) 在 \([a, b]\) 上逐点收敛于 \(f(x)\)；

      2. 导函数列 \(\{f_n'(x)\}\) 在 \([a, b]\) 上一致收敛于 \(g(x)\)，

      则 \(f(x)\) 在 \([a, b]\) 上可微，且 \(f' = g, \quad f_n(x) \rightrightarrows f(x) \quad ([a, b])\)。

      换号公式： \(\left[\lim_{n \to \infty} f_n(x)\right]' = \lim_{n \to \infty} \left[f_n(x)\right]'\)

      证明

      第一步：证明 \(f_n(x) \rightrightarrows f(x)\)（\([a,b]\)）

      • 由条件 1，\(\lim_{n\to\infty} f_n(x_0)\)（\(x_0\in[a,b]\)）存在，

        \(\iff\forall\varepsilon>0,\ \exists N_1>0,\ \forall m>n>N_1:\ |f_n(x_0)-f_m(x_0)| < \frac{\varepsilon}{2}\)

        由条件 2，\(f_n'(x)\rightrightarrows g(x)\)（\([a,b]\)）

        \(\iff\exists N_2>0,\ \forall m>n>N_2,\ \forall x\in[a,b]:\ |f_n'(x)-f_m'(x)| < \frac{\varepsilon}{2(b-a)}\)

        （目标是推出 \(|f_n(x)-f_m(x)|\) 可以无限小）

        取 \(N = \max(N_1, N_2)\)。使用三角不等式。对 \(\forall m > n > N\)，\(\forall x \in [a,b]\)，对函数 \(f_n - f_m\) 在 \(x_0\) 与 \(x\) 之间应用 拉格朗日中值定理。

        \(|f_n(x)-f_m(x)| \leq \underbrace{|[f_n(x)-f_m(x)]-[f_n(x_0)-f_m(x_0)]|}_{拉格朗日中值定理, [f_n'(\xi)-f_m'(\xi)]|x-x_0|< \frac{\varepsilon}{2(b-a)}\cdot(b-a) = \frac{\varepsilon}{2}<\varepsilon/2} + \underbrace{|f_n(x_0)-f_m(x_0)|}_{<\varepsilon/2} < \varepsilon\)

        由 Cauchy 准则，\(\{f_n(x)\}\) 在 \([a,b]\) 上一致收敛。其极限即为 \(f(x)\)（由条件 1 逐点收敛已知），故 \(f_n(x) \rightrightarrows f(x) \quad ([a,b])\)。

      第二步：证明 \(f(x)\) 在 \([a,b]\) 上可微，且 \(f' = g\)

      • 对固定 \(t\in[a,b]\)，令

        \(h_n(x) = \frac{f_n(x)-f_n(t)}{x-t}\quad(x\neq t),\qquad h_n(t) = f_n'(t)\)

        \(h(x) = \frac{f(x)-f(t)}{x-t}\quad(x\neq t),\qquad h(t) = g(t)\)

        由于 \(f_n\) 在 \([a,b]\) 上可微，\(h_n(x)\) 在 \(t\) 处连续（由导数定义），故 \(h_n(x) \in C[a,b]\)

        证明 \(h_n(x) \rightrightarrows h(x)\)（\([a,b]\)）：

        \(\forall m>n>N\)

        \(\forall x\in[a,b]\setminus\{t\}\)，\(|h_n(x)-h_m(x)| \leq\underbrace{\frac{|[f_n(x)-f_m(x)]-[f_n(t)-f_m(t)]|}{|x-t|}=|f_n'(\xi)-f_m'(\xi)|}_{拉格朗日中值定理} < \frac{\varepsilon}{2(b-a)}\)

        当 \(x=t\) 时，\(|h_n(t)-h_m(t)| = |f_n'(t)-f_m'(t)| < \frac{\varepsilon}{2(b-a)}\)，同样成立。

        由 Cauchy 准则，\(\{h_n(x)\}\) 一致收敛。其极限函数恰好是 \(h(x)\)（由逐点收敛可验证），故 \(h_n(x) \rightrightarrows h(x) \quad (x\in[a,b])\)。

        利用连续性定理换序：

        由于 \(h_n(x)\in C[a,b]\) 且 \(h_n(x)\rightrightarrows h(x)\)，由阿贝尔连续性定理，\(h(x)\in C[a,b]\)，从而 \(\lim\limits_{x\to t}h(x)=h(t)\)，即 \(f'(t)=g(t)\)。

      \(\blacksquare\)

    • 函数列一致收敛的等价定义（利用点列极限）：\(f_n(x) \rightrightarrows f(x)\ (x\in D) \iff \forall{x_n}\subset D,\ \lim_{n\to\infty}|f_n(x_n)-f(x_n)|=0\)

      证明

      必要性：由确界极限 \(\sup_{x\in D}|f_n(x)-f(x)|\to 0\) 直接得到。\(\square\)

      充分性：反证法。

      假设 \(f_n(x)\) 在 \(D\) 上不一致收敛于 \(f(x)\)，即：

      \(\exists\varepsilon_0>0,\ \forall N,\ \exists n_0>N,\ \exists x_0\in D:\ |f_{n_0}(x_0)-f(x_0)|\geq\varepsilon_0\)

      逐步取：

      • \(N=1\)：\(\exists n_1>1,\ \exists\xi_1\in D\)，使 \(|f_{n_1}(\xi_1)-f(\xi_1)|\geq\varepsilon_0\)
      • \(N=n_1\)：\(\exists n_2>n_1,\ \exists\xi_2\in D\)，使 \(|f_{n_2}(\xi_2)-f(\xi_2)|\geq\varepsilon_0\)
      • \(N=n_2\)：\(\exists n_3>n_2,\ \exists\xi_3\in D\)，使 \(|f_{n_3}(\xi_3)-f(\xi_3)|\geq\varepsilon_0\)
      • \(\cdots\)

      如此类推，得到点列 \({\xi_k}\subset D\)，满足

      \(|f_{n_k}(\xi_k)-f(\xi_k)|\geq\varepsilon_0 \not\to 0\)

      这与已知条件矛盾。\(\blacksquare\)

    函数项级数的收敛¶

    • 定义：设 \(u_n(x)\ (n = 1, 2, \cdots)\) 是具有公共定义域 \(D\) 的一列函数。把它们用加号连接起来得到 \(\sum_{n=1}^{\infty} u_n(x) = u_1(x) + u_2(x) + \cdots + u_n(x) + \cdots\) 称为函数项级数。

      部分和函数列 \(S_n(x) = \sum_{k=1}^{n} u_k(x)\)。

      \(S_n(x)\) 的点态收敛域 \(E\) 称为级数的点态收敛域，点态极限称为级数的和函数。\(S(x)=\sum_{n=1}^\infty u_n(x),x\in E\)。

    函数项级数的一致收敛¶

    • 定义：给定 \(\sum_{n=1}^{\infty} u_n(x)\)，如果相应的部分和函数列 \(\{S_n(x)\}\) 在集合 \(E\) 上一致收敛于其和函数 \(S(x)\)，则称 \(\sum_{n=1}^{\infty} u_n(x)\) 在 \(E\) 上一致收敛。

      \(\sum_{n=1}^\infty u_n(x)\) 在 \(E\) 上一致收敛

      \(\iff S_n(x) \rightrightarrows S(x)\ (x\in E)\)

      \(\iff\forall \varepsilon > 0,\ \exists N,\ \forall n > N,\ \forall x \in E:\ |S_n(x) - S(x)| < \varepsilon\)

      \(\iff\forall \varepsilon > 0,\ \exists N,\ \forall n > N,\ \forall x \in E:\ |\sum_{k=n+1}^\infty u_k(x)| < \varepsilon\)

    • 定理（柯西准则）：\(\sum_{n=1}^\infty u_n(x)\) 在 \(E\) 上一致收敛

      \(\iff\forall \varepsilon > 0,\ \exists N > 0,\ \forall n > N,\ \forall p\in\mathbb Z^+,\ \forall x \in E:\) \(|S_{n+p}(x) - S_n(x)| < \varepsilon\)

      \(\iff\forall \varepsilon > 0,\ \exists N > 0,\ \forall n > N,\ \forall p\in\mathbb Z^+,\ \forall x \in E:\) \(|\sum_{k=n+1}^{n+p}u_k(x)| < \varepsilon\)

    • 定理（必要条件）：如果 \(\sum_{n=1}^{\infty} u_n(x)\) 在 \(E\) 上一致收敛，则其通项生成的函数列 \(\{u_n(x)\}\) 在 \(E\) 上一致收敛于零。

      \(u_n(x) = S_n(x) - S_{n-1}(x) \rightrightarrows S(x)-S(x)=0\)

    • 定理（Weierstrass 判别法，优级数判别法）：给定 \(\sum u_n(x)\)，如果存在一列正数 \(M_n\)，使得

      • \(|u_n(x)| \leq M_n\)，\(\forall x \in E,\ n = 1, 2, \cdots\)，
      • 级数 \(\sum M_n\) 收敛，

      则 \(\sum_{n=1}^{\infty} u_n(x)\) 在 \(E\) 上绝对收敛且一致收敛。

      证明

      由 \(\sum M_n\) 收敛，对 \(\forall\varepsilon>0\)，\(\exists N\)，\(\forall n>N\)，\(\forall p\geq 1\)：

      \(\left|\sum_{k=n+1}^{n+p} u_k(x)\right| \leq \sum_{k=n+1}^{n+p} |u_k(x)| \leq \sum_{k=n+1}^{n+p} M_k < \varepsilon\)

      对所有 \(x\in E\) 一致成立，由 Cauchy 准则即得。\(\blacksquare\)

      例

      当 \(p>1\) 时，级数 \(\sum_{n=1}^{\infty}\dfrac{\sin nx}{n^p}\) 在整个数轴上一致收敛。

      取 \(M_n = \frac{1}{n^p}\)，则

      \(\left|\frac{\sin nx}{n^p}\right| \leq \frac{1}{n^p} = M_n, \quad \forall x\in\mathbb{R}\)

      又 \(p>1\) 时 \(\sum \frac{1}{n^p}\) 收敛（\(p\)-级数），由 Weierstrass 判别法，原级数在 \(\mathbb{R}\) 上一致收敛。

      设定义在非空集 \(E\) 上的函数列 \(\{f_n(x)\}\) 满足：存在正数列 \(M_n\) 使得

      \(|f_{n+1}(x) - f_n(x)| \leq M_n,\quad \forall x\in E,\ n=1,2,\cdots\)

      且 \(\sum_{n=1}^{\infty} M_n\) 收敛，则 \({f_n(x)}\) 在 \(E\) 上一致收敛。

      证明

      由条件 \(|f_{k+1}(x)-f_k(x)|\leq M_k\) 及 \(\sum M_k\) 收敛，对 \(\forall\varepsilon>0\)，\(\exists N\)，\(\forall m>n>N\)，\(\forall x\in E\)：

      \(|f_m(x)-f_n(x)| = \left|\sum_{k=n}^{m-1}(f_{k+1}(x)-f_k(x))\right| \leq \sum_{k=n}^{m-1} M_k < \varepsilon\)

      由 Cauchy 准则，\({f_n(x)}\) 在 \(E\) 上一致收敛。\(\blacksquare\)

    • 定理（Dirichlet）：设：

      • \(\sum v_n(x)\) 的部分和函数列在 \(E\) 上一致有界：\(|S_n(x)| \leq M\)，\(\forall x,\ \forall n\)；
      • 对于固定 \(x \in E\)，\(\{u_n(x)\}\) 都是单调数列；
      • \(u_n(x) \rightrightarrows 0\)（\(x \in E\)）。

      则 \(\sum u_n(x) v_n(x)\) 在 \(E\) 上一致收敛。

    • 定理（Abel）：设：

      • \(\sum v_n(x)\) 在 \(E\) 上一致收敛；
      • 对于固定 \(x \in E\)，\(\{u_n(x)\}\) 都是单调数列；
      • \(\{u_n(x)\}\) 在 \(E\) 上一致有界。

      则 \(\sum u_n(x) v_n(x)\) 在 \(E\) 上一致收敛。

    和函数的性质¶

    • 定理（阿贝尔连续性定理）：设 \(\sum_{n=1}^{\infty} u_n(x)\) 在 \([a,b]\) 上一致收敛，且 \(u_n(x) \in C[a,b]\)，则和函数 \(S(x)=\sum_{n=1}^\infty u_n(x) \in C[a,b]\)。即 \(\lim\limits_{x\to x_0}\sum_{n=1}^\infty u_n(x)=\sum_{n=1}^\infty \lim\limits_{x\to x_0}u_n(x)\)。

      证明

      \(\underbrace{u_n \in C}_{\text{每项连续}} \Rightarrow \underbrace{S_n \in C}_{\text{有限和连续，自动成立}} \xrightarrow{S_n \rightrightarrows S\ \text{（一致）}} \underbrace{S \in C}_{\text{无限和连续，需要条件}}\)

      推论：设 \(u_n(x) \in C(a,b)\)，且对于任意有界闭子区间 \([c,d] \subset (a,b)\)，\(\sum_{n=1}^{\infty} u_n(x)\) 在 \([c,d]\) 上一致收敛，则和函数 \(S(x) \in C(a,b)\)。

      例

      命题：讨论 \(S(x) = \displaystyle\sum_{n=1}^{\infty}\left(\dfrac{1}{n}+x\right)^n\) 在整个 \((-1,1)\) 上的连续性。

      证明（用推论，Weierstrass 判别）：

      对任意 \([c,d]\subset(-1,1)\)，取 \(r = \max(|c|,|d|) < 1\)，则 \(|x|\leq r\)，\(\forall x\in[c,d]\)。

      关键估计：对充分大的 \(n\)（使 \(\frac{1}{n}+r < 1\)），取 \(q\) 满足 \(r < q < 1\)，当 \(n\geq N_0\)（\(N_0\) 使 \(\frac{1}{n}+r \leq q\)）时：

      \(\left|\left(\frac{1}{n}+x\right)^n\right| \leq \left(\frac{1}{n}+r\right)^n \leq q^n\)

      由 Weierstrass 判别法（\(\displaystyle\sum q^n\) 收敛，\(0<q<1\)），\(\displaystyle\sum\left(\frac{1}{n}+x\right)^n\) 在 \([c,d]\) 上一致收敛。

      每项 \(\left(\dfrac{1}{n}+x\right)^n\in C[c,d]\)，由推论：

      \(S(x) \in C[c,d]\)

      因 \([c,d]\subset(-1,1)\) 任意，故 \(S(x)\in C(-1,1)\)。\(\blacksquare\)

    • 定理（逐项积分）：设 \(\sum u_n(x)\) 在 \([a,b]\) 上满足

      • \(u_n(x) \in R[a,b]\)；
      • \(\sum u_n(x)\) 在 \([a,b]\) 上一致收敛。

      则其和函数在 \([a,b]\) 上黎曼可积，且

      \(\int_a^b \sum_{n=1}^{\infty} u_n(x)dx = \sum_{n=1}^{\infty} \int_a^b u_n(x)dx\)

      证明

      证明（用函数列的逐项积分定理）：

      令 \(S_n(x) = \sum_{k=1}^n u_k(x)\)，验证函数列定理的条件：

      • \(S_n(x)\in R[a,b]\)：有限个可积函数之和可积。✅️
      • \(S_n(x)\rightrightarrows S(x)\)（\([a,b]\) 上一致收敛）：即 \(\sum u_n(x)\) 一致收敛，正是条件二。✅️

      由函数列的逐项积分定理，

      \(\int_a^b S(x)dx = \lim_{n\to\infty}\int_a^b S_n(x)dx = \lim_{n\to\infty}\sum_{k=1}^{n}\int_a^b u_k(x)dx = \sum_{n=1}^{\infty}\int_a^b u_n(x)dx \qquad \blacksquare\)

    • 定理（逐项微分）：设 \(\sum u_n(x)\) 满足

      • \(u_n(x)\in D[a,b]\)；
      • \(\sum u_n(x)\) 在 \([a,b]\) 上逐点收敛；
      • \(\sum u_n'(x)\) 在 \([a,b]\) 上一致收敛。

      则其和函数在 \([a,b]\) 上可微，且 \(\left[\sum_{n=1}^{\infty} u_n(x)\right]' = \sum_{n=1}^{\infty} u_n'(x),\, \forall x\in[a,b]\)

      证明

      证明（用函数列的逐项可微性定理）：

      令 \(S_n(x) = \sum_{k=1}^{n} u_k(x)\) 为部分和函数列。由条件逐条验证：

      验证函数列定理的三个条件：

      • \(S_n(x)\in D[a,b]\)：因为 \(u_k\in D[a,b]\)，有限和可微，故 \(S_n\in D[a,b]\)。✅️
      • \(S_n(x)\) 在 \([a,b]\) 上逐点收敛：即 \(\sum u_n(x)\) 逐点收敛，这正是条件二。✅️
      • \(S_n'(x)\) 在 \([a,b]\) 上一致收敛：注意 \(S_n'(x) = \left[\sum_{k=1}^{n} u_k(x)\right]' = \sum_{k=1}^{n} u_k'(x)\)，即 \(S_n'(x)\) 就是 \(\sum u_n'(x)\) 的部分和，由条件三，\(S_n'(x)\) 一致收敛。✅️

      故由函数列的逐项可微性定理，\(S(x) = \lim_{n\to\infty}S_n(x)\) 在 \([a,b]\) 上可微，且

      \(S'(x) = \lim_{n\to\infty}S_n'(x) = \lim_{n\to\infty}\sum_{k=1}^{n}u_k'(x) = \sum_{n=1}^{\infty}u_n'(x) \qquad \blacksquare\)

      例

      例 1

      证明：函数 \(f(x) = \displaystyle\sum_{n=0}^{\infty} \dfrac{x^{3n}}{(3n)!}\) 在整个数轴上有定义且无穷可微。

      证明：

      设 \(u_n(x) = \dfrac{x^{3n}}{(3n)!}\)，\(u_n^{(k)}(x) = \dfrac{(3n)!}{(3n-k)!} \cdot \dfrac{x^{3n-k}}{(3n)!} = \dfrac{x^{3n-k}}{(3n-k)!}\)（当 \(3n \ge k\) 时）。

      对任意固定 \(M > 0\)，在 \([-M, M]\) 上：

      $ \left|u_n^{(k)}(x)\right| = \left|\dfrac{x^{3n-k}}{(3n-k)!}\right| \le \dfrac{M^{3n-k}}{(3n-k)!} \le \dfrac{M^{3n}}{(3n-k)!} $

      由于 \(\displaystyle\sum_{n=0}^{\infty} \dfrac{M^{3n}}{(3n)!}\) 收敛（可由比值判别法验证，\(\dfrac{a_{n+1}}{a_n} = \dfrac{M^3}{(3n+3)(3n+2)(3n+1)} \to 0\)），由 Weierstrass M-判别法，\(\displaystyle\sum_{n=0}^{\infty} u_n^{(k)}(x)\) 在 \([-M,M]\) 上一致收敛，从而由逐项微分定理，\(f(x)\) 在 \([-M,M]\) 上 \(k\) 次可微。

      由 \(M\) 的任意性，\(f(x)\) 在 \(\mathbb{R}\) 上无穷可微。\(\blacksquare\)

      例 2

      设级数 \(\displaystyle\sum_{n=1}^{\infty} a_n\) 收敛，证明：函数 \(f(x) = \displaystyle\sum_{n=1}^{\infty} \dfrac{a_n}{n^x}\) 在 \([0,+\infty)\) 上连续，在 \((0,+\infty)\) 上无穷可微。

      证明：

      连续性：

      • 级数 \(\sum a_n\) 是常数项级数且已知收敛，故它在在 \([0,+\infty)\) 上一致收敛；
      • \(\forall x\in[0,+\infty)\)，\(\{n^{-x}\}\) 关于 \(n\) 单调不增；
      • \(\forall x\in[0,+\infty],n\in\mathbb N^*\)，\(|n^{-x}|\leq n^0=1\)。

      由 Abel 判别法，级数 \(\displaystyle\sum \dfrac{a_n}{n^x}\) 在 \([0,+\infty)\) 上一致收敛。又每一项 \(\left\{\dfrac{a_n}{n^x}\right\}\) 在 \([0,+\infty)\) 上均连续，故核函数 \(f(x)\in[0,+\infty)\)。

      无穷可微：

      \(\left(\dfrac{a_n}{n^x}\right)^{(k)} = (-1)^k\dfrac{a_n (\ln n)^k}{n^x}\)

      对任意 \([a, b] \subset (0, +\infty)\)（\(0 < a < b\)）：

      • \(\sum a_n\) 收敛，则其部分和有界，\(\sum a_n\) 在 \([a,b]\) 上一致有界；
      • \(\forall x\geq a\)，当 \(n\) 充分大时 \(\left\{\dfrac{(\ln n)^k}{n^x}\right\}\) 关于 \(n\) 单调递减（可求导证明）；
      • \(\forall x\geq a\)，\(\left|\dfrac{(\ln n)^k}{n^x}\right|\leq \dfrac{(\ln n)^k}{n^a}\to 0\)，故 \(\dfrac{(\ln n)^k}{n^x}\rightrightarrows 0\,(n\to \infty)\)。

      因为 \(k\) 和 \([a,b]\) 时任意的，由逐项求导定理，\(f^{(k)}(x) = (-1)^k \displaystyle\sum_{n=1}^{\infty} \dfrac{a_n (\ln n)^k}{n^x}\) 在 \((0,+\infty)\) 上成立。\(\blacksquare\)

      例 3（Zeta 函数）

      证明：\(\zeta(x) = \displaystyle\sum_{n=1}^{\infty} \dfrac{1}{n^x}\) 在 \((1,+\infty)\) 上无穷可微。

      证明：

      对任意 \([a, b] \subset (1, +\infty)\)（\(a > 1\)），\(k\) 阶导数各项为 \(\dfrac{(-\ln n)^k}{n^x}\)，其绝对值不超过 \(\dfrac{(\ln n)^k}{n^a}\)。

      由于 \(\displaystyle\sum_{n=1}^{\infty} \dfrac{(\ln n)^k}{n^a}\) 收敛（当 \(a > 1\) 时），由 Weierstrass M-判别法，\(k\) 阶导数级数在 \([a,b]\) 一致收敛，从而可逐项微分，\(\zeta^{(k)}(x) = (-1)^k \displaystyle\sum_{n=1}^{\infty} \dfrac{(\ln n)^k}{n^x}\)。 由 \(a > 1\) 任意，\(\zeta(x)\) 在 \((1,+\infty)\) 无穷可微。\(\blacksquare\)

    • 例 (Dini 定理)：设 \(f_n(x)\) 为 \([a,b]\) 上非负连续函数，且对每个 \(x \in [a,b]\)，\(f_n(x)\) 关于 \(n\) 单调递减趋于零，则 \(f_n(x) \rightrightarrows 0\)，\(x\in[a,b]\)。

      证明

      证明 1：

      对 \(\forall \epsilon > 0\)，要找 \(N > 0\)，使得当 \(n > N\) 时，\(0 \le f_n(x) < \epsilon\)，\(\forall x \in [a,b]\)。

      记 \(A_n = \{x \in [a,b] \mid f_n(x) \ge \epsilon\}\)。由 \(f_n(x)\) 关于 \(n\) 单调递减，有 \(A_n \supset A_{n+1}\)（\(\forall n\)）。

      目标：证明存在某个 \(A_n\) 为空集。

      （反证法）设 \(A_n\) 都不是空集，取 \(x_n \in A_n\)，则 \(\{x_n\} \subset [a,b]\)，由 Bolzano-Weierstrass 定理，存在收敛子列 \(x_{n_k} \to x_0 \in [a,b]\)（\(k \to \infty\)）。

      此时，\(\forall K \ge 1\)，有 $A_K \supset A_{n_K} \supset {x_{n_K}, x_{n_{K+1}}, \cdots} $

      当 \(k \ge K\) 时，有 \(f_K(x_{n_k}) \ge \epsilon\)。令 \(k \to \infty\)，由 \(f_K\) 的连续性，有 \(f_K(x_0) \ge \epsilon\)。

      这与已知条件 \(f_n(x_0) \to 0\)（即对充分大的 \(n\) 有 \(f_n(x_0) < \epsilon\)）矛盾！\(\blacksquare\)

      证明 2（常规证法）：

      假设 \(f_n(x)\) 不一致收敛于零，则 \(\exists \epsilon_0 > 0\)，\(\forall N \in \mathbb{N}\)，\(\exists n_N > N\)，\(\exists x_N \in [a,b]\) 使得

      $ f_{n_N}(x_N) = |f_{n_N}(x_N)| \ge \epsilon_0. $

      故存在收敛子列 \(\{x_{n_k}\} \subset [a,b]\)，使得

      $ f_{n_k}(x_{n_k}) = |f_{n_k}(x_{n_k})| \ge \epsilon_0. $

      不妨设 \(x_{n_k} \to x_0 \in [a,b]\)。由于 \(f_n(x_0) \to 0\)，则对 \(\epsilon = \dfrac{\epsilon_0}{4}\)，\(\exists N > 0\)，\(\forall n > N\)，有 \(f_n(x_0) = |f_n(x_0)| < \epsilon\)。

      取 \(n_0 = N + 1\)，再由 \(f_{n_0}(x)\) 的连续性，\(\exists \delta > 0\)，当 \(x \in U(x_0,\delta) \cap [a,b]\) 时，有

      $ |f_{n_0}(x) - f_{n_0}(x_0)| < \epsilon. $

      现取一个 \(n_k > n_0\)，使得 \(|x_{n_k} - x_0| < \delta\)，则有 \(f_{n_0}(x) \ge f_{n_k}(x) \ge 0\)，因此

      $ \epsilon_0 \le f_{n_k}(x_{n_k}) \le f_{n_0}(x_{n_k}) = |f_{n_0}(x_{n_k})| \le |f_{n_0}(x_{n_k}) - f_{n_0}(x_0)| + |f_{n_0}(x_0)| < 2\epsilon = \dfrac{\epsilon_0}{2}. $

      矛盾！\(\blacksquare\)

    • 构造具有特殊性质的函数

      例

      例

      设 \({x_n} \subset [0,1]\) 是一个各项互不相同的序列，证明：函数 \(S(x) = \sum_{n=1}^{\infty} \dfrac{\operatorname{sgn}(x-x_n)}{2^n}\) 的和函数当且仅当 \(x = x_n\) 时不连续。

      例（V. D. Waerden，处处不可导的连续函数）

      设 \(f(x) = |x|\)，\(x \in \left[-\dfrac{1}{2}, \dfrac{1}{2}\right]\)，然后将 \(f(x)\) 以 \(1\) 为周期延拓至整个数轴，则 \(\sum_{n=1}^{\infty} \dfrac{f(4^n x)}{4^n}\) 的和函数是整个数轴上的连续函数，但处处不可导！

    • 考虑连续函数用多项式函数逼近的问题。多项式函数是最简单的函数，因为只涉及到四则运算，而不涉及更复杂的运算，相应的函数值容易计算，性质也容易把握。

      定理（Weierstrass 第一逼近定理）：设 \(f(x) \in C[a,b]\)，则 \(\forall \epsilon > 0\)，存在多项式 \(P(x)\)，使得 \(|f(x) - P(x)| < \epsilon, \quad \forall x \in [a,b]\)，且 \(P(a) = f(a)\)，\(P(b) = f(b)\)。

      可以等价地叙述为：存在多项式函数列 \(\{P_n(x)\}\) 在区间 \([a,b]\) 上一致收敛于 \(f(x)\)。

      证明

      Bernstein 多项式：

      给定连续函数 \(f(x)\)，定义多项式函数列（Bernstein 多项式）如下：

      $ B_n(f, x) = \sum_{k=0}^{n} C_n^k f\left(\dfrac{k}{n}\right) x^k (1-x)^{n-k}, \quad x \in [0,1]. $

      可得 \(B_n(f, 0) = f(0)\)，\(B_n(f, 1) = f(1)\)。

      目标： \(B_n(f, x) \rightrightarrows f(x)\)（\([0,1]\)）。

      引理：

      • \(\sum_{k=0}^{n} C_n^k x^k (1-x)^{n-k} = 1\)
      • \(\sum_{k=0}^{n} k C_n^k x^k (1-x)^{n-k} = nx\)
      • \(\sum_{k=0}^{n} k(k-1) C_n^k x^k (1-x)^{n-k} = n(n-1)x^2\)

      （以上三式均由二项式定理 \((x+y)^n = \displaystyle\sum_{k=0}^{n} C_n^k x^k y^{n-k}\) 对 \(x\) 求导，令 \(y=1-x\) 推出。）

      命题：

      \(\sum_{k=0}^{n} (k - nx)^2 C_n^k x^k (1-x)^{n-k} \le \dfrac{n}{4}, \quad \forall x \in [0,1],\ \forall n.\)

      注意到

      $ f(x) = \sum_{k=0}^{n} f(x) C_n^k x^k (1-x)^{n-k}, \quad x \in [0,1]. $

      从而有

      $ |f(x) - B_n(f,x)| \le \sum_{k=0}^{n} \left|f(x) - f\left(\dfrac{k}{n}\right)\right| C_n^k x^k (1-x)^{n-k}. $

      由于 \(f \in C[0,1]\)，从而一致连续。

      技巧：将上述和式分成两部分来估计。

      记

      \(A_x = \left\{k \in \mathbb{Z}^+ : \left|\dfrac{k}{n} - x\right| < \delta,\ 0 \le k \le n\right\},\)

      \(B_x = \left\{k \in \mathbb{Z}^+ : \left|\dfrac{k}{n} - x\right| \ge \delta,\ 0 \le k \le n\right\}.\)

      则利用一致连续的性质有

      $ \sum_{k \in A_x} \left|f(x) - f\left(\dfrac{k}{n}\right)\right| C_n^k x^k (1-x)^{n-k} \le \epsilon \sum_{k \in A_x} C_n^k x^k (1-x)^{n-k} \le \epsilon. $

      而对于第二部分，需要用到前面的命题：

      \(\sum_{k \in B_x} \left|f(x) - f\left(\dfrac{k}{n}\right)\right| C_n^k x^k (1-x)^{n-k} \le 2M \sum_{k \in B_x} C_n^k x^k (1-x)^{n-k}\)

      \(\le \dfrac{2M}{n^2\delta^2} \sum_{k \in B_x} (k-nx)^2 C_n^k x^k (1-x)^{n-k} \le \dfrac{2M}{n^2\delta^2} \cdot \dfrac{n}{4} = \dfrac{M}{2n\delta^2}.\)

      （其中用到了：当 \(k \in B_x\) 时，\(\dfrac{\frac k n-x}{\delta}\geq 1\)，\(\left(\dfrac{k-nx}{n\delta}\right)^2 \ge 1\)，即 \((k-nx)^2 \ge n^2\delta^2\)。）

      取充分大的 \(n\) 使得 \(\dfrac{M}{2n\delta^2} < \epsilon\)，即可完成证明。\(\blacksquare\)

    • 阿尔采拉-阿斯科利定理

      数列的致密性定理能否推广至函数列情形？即是否每个逐点有界的函数列都有收敛的子列？

      • 定义（等度连续）：设 \(\{f_n(x)\}\) 是区间 \([a,b]\) 上的连续函数列，如果

        $\forall \epsilon > 0, \exists \delta > 0, \forall x, y \in [a,b]: |x-y| < \delta, |f_n(x) - f_n(y)| < \epsilon,\quad \forall n, $

        则称 \({f_n(x)}\) 在 \([a,b]\) 上等度连续。

      • 有界闭区间上一致收敛的连续函数列必满足在闭区间上一致有界且等度连续。

      • 定理（阿尔采拉-阿斯科利）：有界闭区间 \([a,b]\) 上逐点有界并且等度连续的连续函数列必有在 \([a,b]\) 一致收敛的子列。
