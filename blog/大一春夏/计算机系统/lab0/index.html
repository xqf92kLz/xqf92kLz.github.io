    Verilog 基础¶

    1. module：电路模块

      module 块定义了一个独立电路单元的边界。它声明了模块的名字以及它与外部世界连接的引脚 (Ports)。

      // 推荐写法：在声明的同时定义输入输出
module main (
    input I0, // 输入引脚 0
    input I1, // 输入引脚 1
    input I2, // 输入引脚 2
    output O   // 输出引脚
);
    // 内部电路逻辑...
endmodule

    2. wire：定义线路

      wire 对应电路中的一根真实导线或一个信号网路。

      • 特性：它不存储电荷，只是传递电平信号。
      • 多位声明：wire s_logisimNet0; 声明一个 1-bit 的连线。

    3. assign：连

      assign 语句的作用是将某个信号“驱动”到一根导线上。

      规则 物理含义 错误后果
      唯一驱动 一根 wire 必须且只能由一个输入源驱动 Multi-driven (短路)：两个输出接在一起会烧毁器件
      禁止环路 assign a = b; assign b = a; 逻辑振荡/悬空：电路状态不可控
      必须驱动 使用 wire 前必须给它分配输入 高阻态 (Hi-Z)：类似于 C 语言未初始化的变量，读出的是随机垃圾值

      常量赋值

      • 1'b1：代表高电平（Vcc / 逻辑 1）。
      • 1'b0：代表低电平（GND / 逻辑 0）。

    4. 逻辑运算与门电路

      逻辑功能 运算符语法 结构化调用（实例化）
      非 (NOT) assign O = ~I; not gate1 (O, I);
      与 (AND) assign O = I1 & I2; and gate1 (O, I1, I2);
      或 (OR) assign O = I1 | I2; or gate1 (O, I1, I2);

    5. 模块实例化：调用现成电路

      当电路变得复杂时，我们会调用预先定义好的模块（类似 C 语言调用函数，但本质是克隆硬件）。

      • 名关联方式 (Named Port Connection)：这种方式明确指出哪根线连哪个引脚，不会因顺序错误导致短路。

        // 实例化一个三输入与门
AND_GATE_3_INPUTS GATES_1 (
    .input1(s_logisimNet2),  // 将导线 Net2 接到引脚 input1
    .input2(s_logisimNet4),
    .input3(s_logisimNet3),
    .result(s_logisimNet10)  // 输出驱动导线 Net10
);
// 实例化一个四输入或门
OR_GATE_4_INPUTS GATES_5 (
    .input1(s_logisimNet10),
    .input2(s_logisimNet6),
    .input3(s_logisimNet7),
    .input4(s_logisimNet8),
    .result()   // 如果希望 result 端口悬空，需要显式声明悬空该端口
);

        悬空处理：如果模块的某个输出引脚不需要使用，必须显式留空：.result()。

    核心思想：先有电路，后有代码！

    1. 不要把 Verilog 当成 C 语言：
      • C 语言是顺序执行的指令。
      • Verilog 是并行的硬件描述。所有 assign 语句在物理上是同时存在的，没有先后顺序。
    2. 避免逻辑抽象陷阱：
      • 仅仅通过卡诺图化简写出的 & | ~ 表达式虽然逻辑正确，但若不考虑电气特性（如驱动能力、延迟），在实际芯片中可能无法工作。
    3. 电气检查清单：
      • 检查是否有 wire 被重复赋值（Multi-driven）？
      • 检查是否有 input 被当成 output 赋值了？
      • 检查是否有 wire 忘了给输入信号？

    XDC 基础¶

    XDC 是基于 Tcl (Tool Command Language) 脚本语言的约束文件。

    • 核心功能：告诉 FPGA 开发工具（如 Vivado），你的 Verilog 代码中的信号（Ports）应该连接到芯片上哪一个具体的物理引脚（Package Pin），以及采用什么样的电平标准（IO Standard）。
    • 运行机制：Vivado 本质上是一个 Tcl 解释器，XDC 里的每一行都是一条 Tcl 指令。

    一条标准的约束指令通常由四部分组成： set_property <属性名> <属性值> [get_ports {信号名}]

    • set_property：Tcl 动词，表示“设置属性”。
    • PACKAGE_PIN：引脚位置属性。例如 J15 是芯片上的物理坐标。
    • IOSTANDARD：电平标准属性。常用 LVCMOS33（3.3V 低电压 CMOS）。
    • [get_ports {信号名}]：
      • get_ports 是 Tcl 函数，用于从设计网表中搜寻端口。
      • 方括号 [] 表示先执行括号内的函数，并将结果返回给 set_property。
      • 大括号 {} 确保信号名被当作一个整体字符串处理。

    三大类约束：

    1. 物理位置约束 (Location)

      将代码端口“焊”在芯片引脚上。

      # 将信号 SW0 绑定到物理引脚 J15
set_property PACKAGE_PIN J15 [get_ports {SW0}]

    2. 电平标准约束 (I/O Standard)

      定义引脚的电气特性。如果不写这一行，Bitstream 往往无法生成。

      # 设置 SW0 为 3.3V 逻辑电平
set_property IOSTANDARD LVCMOS33 [get_ports {SW0}]

    3. 简写合并格式

      set_property -dict { PACKAGE_PIN H17 IOSTANDARD LVCMOS33 } [get_ports {LD0}]

    Logisim¶

    • 添加标签：点击选中元件，在左侧 Properties 面板中找到 Label，输入名称并回车。

    • 连线：

      • 操作：选择上方的小箭头图标（快捷键 Ctrl-2），将鼠标移至一个元件的引脚（会有绿色圆圈提示），按住鼠标左键并拖动到另一个元件的引脚上。
      • 直线拐弯：默认只走直线。如果需要拐弯，先拉到拐角点松开，再从拐角点继续拉。
      • 节点：当两条线垂直相交且有连接，会有实心圆点。没有点说明只是交叉但没连通。

    • 修改输入端数量：默认的逻辑门（如 AND, OR）通常是 2 输入的。如果需要修改，先选中逻辑门，在左侧的 Properties 面板中找到 Number Of Inputs 进行修改。

    • 切换输入端口的值：默认情况下输入端口的值为 0。选择上方的小手工具（快捷键 Ctrl-1），点击输入端口可以让值在 0 和 1 之间切换。

      • 深绿色：代表 0 (低电平 / Low)。
      • 亮绿色：代表 1 (高电平 / High)。
      • 蓝色：代表未知状态（悬空）。
      • 红色：代表逻辑冲突（短路）。

      使用小手工具点击线条可以查看状态。

    Verilator 仿真¶

    // 定义测试平台模块，Testbench 通常没有输入输出引脚
module Testbench;

    // --- 信号声明 ---
    // reg 类型：可以类比为“带锁存功能的寄存器”，可以认为是一个能提供固定输出的变量
    reg I0, I1, I2; 
    // wire 类型：它不存储值，只是实时传递 main 模块计算出的电平结果
    wire O;

    // --- 激励过程 (Initial Block) ---
    // initial 块里的代码从仿真时刻 0 开始执行，且只执行一次。可以给 reg 寄存器赋值
    initial begin
        // 初始状态：将三个输入信号都设为逻辑 0
        // 1'b0 表示：1位宽、二进制、数值为0
        I0=1'b0; I1=1'b0; I2=1'b0;

        // #5 的意义：维持当前输入状态 5 个时间单位。
        // 若无延迟，所有赋值会在瞬间完成，波形图上将看不到稳定的 0 或 1 周期
        #5;

        // 以下步骤是在穷举 3 输入变量的所有组合（从 000 到 111）
        // 这种方法常用于验证真值表
        I0=1'b0; I1=1'b0; I2=1'b1; // 001
        #5;
        I0=1'b0; I1=1'b1; I2=1'b0; // 010
        #5;
        I0=1'b0; I1=1'b1; I2=1'b1; // 011
        #5;
        I0=1'b1; I1=1'b0; I2=1'b0; // 100
        #5;
        I0=1'b1; I1=1'b0; I2=1'b1; // 101
        #5;
        I0=1'b1; I1=1'b1; I2=1'b0; // 110
        #5;
        I0=1'b1; I1=1'b1; I2=1'b1; // 111
        #5;

        // 必须调用 $finish，强制告诉仿真器停止工作，否则仿真时间轴会无限延伸
        $finish; 
    end

    // --- 模块实例化 (DUT: Device Under Test，即被测模块) ---
    // 将 Testbench 里的变量“插”到被测模块 main 对应的引脚上
    main dut( 
        //.I0 是被测模块 main 的引脚名，(I0) 是你在这个 Testbench 里定义的变量名
        .I0(I0), // 将测试平台的 I0 连接到 main 的引脚 I0
        .I1(I1), 
        .I2(I2), 
        .O(O)    // 将 main 的输出引脚 O 连接到测试平台的 wire O
    );

    // --- 仿真波形导出 (针对 Verilator 的设置) ---
    // 如果定义了 VERILATE 宏，则执行以下代码来生成波形文件
    `ifdef VERILATE
        initial begin
            // 生成波形文件 build/verilator/Testbench.vcd，.vcd 文件可以用 GTKWave 软件打开
            $dumpfile({`TOP_DIR,"/Testbench.vcd"});
            // 指定要记录哪些信号的波形，0 表示记录 dut 模块下的所有信号
            $dumpvars(0,dut);
            // 启动记录过程
            $dumpon;
        end
    `endif

endmodule

    综合 (Synthesis)¶

    右键需要综合的模块，然后选择 Set as Top，该模块就会变为顶层模块，之后的 synthensis 操作只针对该模块和它内部的模块进行。例如，设置 AND_GATE_3_INPUTS 为顶层模块则只综合 AND3 电路，而不综合 OR4 电路和 main 电路。

    点击左侧 SYNTHENSIS → Run Sythensis，再点击 OK。

    综合的过程：

    1. 把代码变成一堆“与门”、“或门”、“非门”的连接。

    2. 把真值表结果存进 LUT (Look-Up Table，查找表) 里。

      LUT 本质上是一个“小型内存条”。如 LUT3 有 3 个输入，能产生 1 个输出。它内部存了 8 位数据（\(2^3=8\)），如果设计的 main 电路在输入 110 时应该输出 1，综合器就会在 LUT 的第 6 个格子（二进制 110）里填入 1。

    综合完毕后，点击 SYNTHESIS → Open Synthesized Design → Schematic (原理图)，可以看到综合得到的电路图实现，以及 LUT3。

    所以 Implementation 的主要内容是

    • Placement：映射物理资源，设置 LUT 内容

    • Routing：连接 IO Buffer 和物理资源

    • IO Buffer：启用 IO 相关引脚 buffer
    • Optimization：删除多余资源，改善电气特性

    上板验证¶

    先连好线。

    然后 PROGRAM AND DEBUG → Open Hardware Manager → Open Target → Auto Connect。

    选中 Hardware 中的 xc7a100t 开发板为我们要下载 bitstream 的开发板。

    点击 Program Device 准备载入 bitstream，在目录中寻找准备下板的 bitstream 文件 top.bit，最后点击 Program 上板。

    在板子的最下方边缘，有一排可以上下拨动的黑色小开关。

    • 在拨码开关的正下方，印有非常小的白字，写着 SW0, SW1, SW2... 直到 SW15。SW0 在最右边。

    • 在拨码开关的正上方，有一排 LED 灯，是一排非常小的透明或黄色发光二极管。LD0 对应 SW0 正上方的那个灯，LD1 对应 SW1 正上方那个灯，以此类推。

    接着操纵 SW0-SW2 观察 LD0 的现象。
