    Section 1.1: 命题逻辑 (Propositional Logic)¶

    1. 定义

    • 命题 (Proposition)：命题是一个可以判断真 (True, T) 假 (False, F) 的陈述句。
      • 例题 (是命题)：“月亮是绿奶酪做的”（假）、“杭州是中国的首都”（假）、“1 + 0 = 1”（真）。
      • 例题 (不是命题)：祈使句（如“坐下！”）、疑问句（如“现在几点了？”）、包含未赋值变量的等式（如“\(x + 1 = 2\)”）。

    2. 逻辑连接词 (Connectives) 命题可以通过逻辑连接词组合成复合命题，通常用命题变量（如 \(p, q, r, s\)）表示。

    • 否定 (Negation, \(\neg p\))：即“非”。当 \(p\) 为真时，\(\neg p\) 为假；当 \(p\) 为假时，\(\neg p\) 为真。
      • 例题：\(p\) 代表“地球是圆的”，\(\neg p\) 即“地球不是圆的”。
    • 合取 (Conjunction, \(p \land q\))：即“并且 (AND)”。仅当 \(p\) 和 \(q\) 同时为真时，结果为真；否则为假。
    • 析取 (Disjunction, \(p \lor q\))：即“或者 (OR)”。包含性“或者”，只要 \(p\) 或 \(q\) 至少有一个为真，结果即为真。
    • 异或 (Exclusive OR, \(p \oplus q\))：即“排他性或者 (XOR)”。仅当 \(p\) 和 \(q\) 恰好有一个为真时结果为真；两者同真或同假时结果为假（如“点汤或沙拉，只能选其一”）。
    • 蕴含/条件语句 (Implication, \(p \rightarrow q\))：即“如果 \(p\)，那么 \(q\)”。\(p\) 是前提 (hypothesis)，\(q\) 是结论 (conclusion)。
      • 真值表：仅当 \(p\) 为真且 \(q\) 为假时，\(p \rightarrow q\) 才为假。只要 \(p\) 为假，无论 \(q\) 是真是假，该条件语句都为真。可以将其理解为一种“契约”或“承诺”，只有在前提成立但结论没兑现时，才算违约（假）。
      • 不同英语表达：if \(p\) then \(q\)；\(p\) implies \(q\)；\(q\) unless \(\neg p\)；\(p\) is sufficient for \(q\) (充分条件)；\(q\) is necessary for \(p\) (必要条件)；\(p\) only if \(q\) (\(q\) 是必要条件)。
    • 双条件语句 (Biconditional, \(p \leftrightarrow q\))：即“当且仅当 (if and only if / iff)”。当 \(p\) 和 \(q\) 真值相同时为真，不同时为假。

    3. 条件语句的相关命题 对于条件语句 \(p \rightarrow q\)：

    • 逆命题 (Converse)：\(q \rightarrow p\)。与原命题不等价。
    • 逆否命题 (Contrapositive)：\(\neg q \rightarrow \neg p\)。与原命题逻辑等价。
    • 反命题 (Inverse)：\(\neg p \rightarrow \neg q\)。与原命题不等价（但与其逆命题等价）。
    • 例题：求“天下雨是我不去镇上的充分条件”的逆命题、反命题和逆否命题。
      • 解答：设 \(p\) 为天下雨，\(q\) 为我不去镇上。原命题 \(p \rightarrow q\)。
      • 逆命题 (\(q \rightarrow p\))：如果我不去镇上，那么天在下雨。
      • 反命题 (\(\neg p \rightarrow \neg q\))：如果天不下雨，那么我就会去镇上。
      • 逆否命题 (\(\neg q \rightarrow \neg p\))：如果我去镇上，那么天一定没下雨。

    4. 真值表 (Truth Tables) 构建包含 \(n\) 个命题变量的复合命题真值表时，需要列出所有可能的真值组合，总行数为 \(2^n\) 行。

    Section 1.2: 命题逻辑的应用 (Applications of Propositional Logic)¶

    1. 语句翻译 (Translating English to Propositional Logic) 将自然语言转换为逻辑表达式，消除二义性。

    • 例题：“You can access the internet from campus only if you are a computer science major or you are not a freshman.”。
      • 解答：设 \(a\) = 你可以访问网络，\(c\) = 你是计算机专业学生，\(f\) = 你是新生。句子中包含 "only if"，翻译为：\(a \rightarrow (c \lor \neg f)\)。

    2. 系统说明书一致性 (Consistent System Specifications) 如果能为命题变量找到一种真值指派，使得系统说明书中的所有规则同时为真，则该说明书是“一致的” (consistent)。

    • 例题：判断以下说明书是否一致：1. 诊断信息存储在缓冲区或被重新发送 (\(p \lor q\))；2. 诊断信息没有存储在缓冲区 (\(\neg p\))；3. 如果诊断信息存储在缓冲区，那么它将被重新发送 (\(p \rightarrow q\))。
      • 解答：要使 \(\neg p\) 为真，\(p\) 必须为假 (False)。此时 \(p \lor q\) 要为真，\(q\) 必须为真 (True)。验证第三条：当 \(p\) 为假，\(q\) 为真时，\(p \rightarrow q\) 为真。因此，当 \(p=F, q=T\) 时，三条规范均成立，系统说明书是一致的。

    3. 布尔搜索 (Boolean searches) 布尔搜索本质上是利用命题逻辑中的逻辑连接词（如 AND、OR 等）将不同的搜索条件结合起来，从而完成信息的查询。

    • 例题：用户想要查找与“新墨西哥州（New Mexico）”或者“亚利桑那州（Arizona）”的大学相关的网页。
      • 解答：对上述查找大学的例子，构建的布尔搜索查询表达式为 (NEW AND MEXICO OR ARIZONA) AND UNIVERSITIES。

    4. 逻辑谜题 (Logic Puzzles)

    • 例题 1：岛上有骑士（Knights，永远说真话）和无赖（Knaves，永远说假话）两类人。A 说“B 是个骑士”，B 说“我们俩类型不同”。推断 A 和 B 是什么人？
      • 解答：设 \(p\) 为“A 是骑士”，\(q\) 为“B 是骑士”。A 的陈述等价于 \(q\)；B 的陈述等价于 \(p \oplus q\)。若 A 是骑士，则 A 说真话，所以 B 也是骑士；但若 B 是骑士，B 也该说真话，即“两人类型不同”，这与两人都是骑士矛盾。所以 A 必然是无赖 (False)。既然 A 说假话，那么 B 不是骑士，所以 B 也是无赖 (False)。此时 B 确实是无赖，他说两人类型不同是假话，这与“两人都是无赖”的事实吻合。结论：A 和 B 都是无赖。
    • 例题 2：A 说“我们至少有一个是无赖”，B 没说话。
      • 解答：设 \(p\) 为“A 是骑士”，\(q\) 为“B 是骑士”。A 的陈述是 \(\neg p \lor \neg q\)。若 A 是无赖，则他说的是假话，即不存在无赖，与 A 本身是无赖矛盾。所以 A 必然是骑士。既然 A 是骑士且说真话，那么两人中至少有一个无赖，这说明 B 必然是无赖。结论：A 是骑士，B 是无赖。
    • 例题 3：爸爸对一对儿女说“你们中至少有一个人脸脏了”。两个小孩能看到对方的脸但看不到自己。爸爸问：“你知道自己的脸脏了吗？” 第一遍两人都回答“不知道”。第二遍再问时，两人都回答“知道，我脸脏了”。
      • 解答：如果只有一个人脸脏，脏脸的小孩看到对方脸是干净的，结合爸爸的话，会立刻知道自己脸脏。但第一遍两人都说“不知道”，说明他们都看到了对方是一张脏脸（所以不确定自己脏不脏）。因此，在听到对方回答“不知道”后，两人都能推断出自己必定也是脏脸。

    Section 1.3: 命题等价式 (Propositional Equivalences)¶

    1. 基础定义

    • 永真式/重言式 (Tautology)：永远为真的命题，如 \(p \lor \neg p\)。
    • 矛盾式 (Contradiction)：永远为假的命题，如 \(p \land \neg p\)。
    • 可能式 (Contingency)：既非永真也非矛盾的命题，如 \(p\)。

    2. 逻辑等价 (Logical Equivalence) 如果两个复合命题 \(p\) 和 \(q\) 无论变量如何取值，真值始终相同（即 \(p \leftrightarrow q\) 是永真式），则称它们逻辑等价，记作 \(p \equiv q\)。

    • 证明等价的方法：
      1. 利用真值表穷举比对（简单但变量多时耗时，\(2^n\) 复杂度）。
      2. 利用已有的等价公式一步步推导替代（类似代数演算）。

    3. 核心逻辑等价定律 (Key Logical Equivalences)

    • 蕴含等价式：\(p \rightarrow q \equiv \neg p \lor q\)。
      • 例题：“如果你不努力工作 (\(p\))，就会被解雇 (\(q\))”。等价于“要么你不努力工作 (\(\neg p\))，要么你被解雇 (\(q\))”。
    • 德摩根定律 (De Morgan's Laws)：将否定符移入括号内并反转内部连接符。
      • \(\neg(p \land q) \equiv \neg p \lor \neg q\)
      • \(\neg(p \lor q) \equiv \neg p \land \neg q\)
      • 例题：“Mike 有手机且有台式机”的否定是“Mike 没有手机，或者没有台式机”。
    • 恒等律 (Identity Laws)：\(p \land T \equiv p\), \(p \lor F \equiv p\)。
    • 支配律 (Domination Laws)：\(p \lor T \equiv T\), \(p \land F \equiv F\)。
    • 幂等律 (Idempotent Laws)：\(p \lor p \equiv p\), \(p \land p \equiv p\)。
    • 双重否定律 (Double Negation Law)：\(\neg(\neg p) \equiv p\)。
    • 否定律 (Negation Laws)：\(p \lor \neg p \equiv T\), \(p \land \neg p \equiv F\)。
    • 交换律 (Commutative Laws)：\(p \lor q \equiv q \lor p\), \(p \land q \equiv q \land p\)。
    • 结合律 (Associative Laws)：\((p \land q) \land r \equiv p \land (q \land r)\), \((p \lor q) \lor r \equiv p \lor (q \lor r)\)。
    • 分配律 (Distributive Laws)：\(p \lor (q \land r) \equiv (p \lor q) \land (p \lor r)\), \(p \land (q \lor r) \equiv (p \land q) \lor (p \land r)\)。
    • 吸收律 (Absorption Laws)：\(p \lor (p \land q) \equiv p\), \(p \land (p \lor q) \equiv p\)。

    Section 1.3: 命题等价式 (Propositional Equivalences)¶

    1. 基础定义

    • 永真式 (Tautology)：永远为真的命题，例如 \(p \lor \neg p\)。
    • 矛盾式 (Contradiction)：永远为假的命题，例如 \(p \land \neg p\)。
    • 可能式 (Contingency)：既非永真也非矛盾，真值取决于变量赋值的命题。
    • 逻辑等价 (Logical Equivalence)：如果复合命题 \(p \leftrightarrow q\) 是永真式（即无论变量取值如何，两者真值始终相同），则称 \(p\) 和 \(q\) 逻辑等价，记作 \(p \equiv q\)。

    2. 构造新的逻辑等价式 (Constructing New Logical Equivalences) 除了真值表穷举，我们可以像代数演算一样，利用已知的逻辑等价式一步步推导证明 \(A \equiv B\)（即证明过程为 \(A \equiv A_1 \equiv \dots \equiv B\)）。

    • 例题：证明 \(\neg(p \lor (\neg p \land q))\) 逻辑等价于 \(\neg p \land \neg q\)。

      • 解答推导过程：
        1. \(\neg(p \lor (\neg p \land q))\)
        2. \(\equiv \neg p \land \neg(\neg p \land q)\) (利用第二德摩根定律)
        3. \(\equiv \neg p \land (\neg(\neg p) \lor \neg q)\) (利用第一德摩根定律)
        4. \(\equiv \neg p \land (p \lor \neg q)\) (利用双重否定律)
        5. \(\equiv (\neg p \land p) \lor (\neg p \land \neg q)\) (利用分配律)
        6. \(\equiv F \lor (\neg p \land \neg q)\) (因为 \(\neg p \land p \equiv F\))
        7. \(\equiv (\neg p \land \neg q) \lor F\) (利用交换律)
        8. \(\equiv \neg p \land \neg q\) (利用恒等律)

      • 例题：证明复合命题 \((p \land q) \rightarrow (p \lor q)\) 是一个永真式。

      • 这道题同样使用了类似代数演算的方法，利用已知的逻辑等价律一步步推导出结果为 \(T\)（True）。具体步骤如下：

        1. \((p \land q) \rightarrow (p \lor q)\)
        2. \(\equiv \neg(p \land q) \lor (p \lor q)\) （利用蕴含等价式，即 \(p \rightarrow q \equiv \neg p \lor q\) 将条件符号消除）
        3. \(\equiv (\neg p \lor \neg q) \lor (p \lor q)\) （对左侧括号利用第一德摩根定律）
        4. \(\equiv (\neg p \lor p) \lor (\neg q \lor q)\) （利用或运算的结合律和交换律，将相关的变量组合在一起）
        5. \(\equiv T \lor T\) （利用否定律，已知 \(\neg p \lor p \equiv T\) 且 \(\neg q \lor q \equiv T\)）
        6. \(\equiv T\) （利用支配律得出最终结果为 True，证明完毕）
        7. 证明不等价：要证明两个表达式不逻辑等价，只需构造出一个反例 (Counterexample)，即找到一组真值赋值让两者结果不同即可。
        8. 例题：证明 \((p\to q)\to (r\to s)\) 和 \((p\to r)\to (q\to s)\) 不是逻辑等价的。

      • 考虑构造赋值使命题 A \((p \to q) \to (r \to s) = \mathbf{F}\)，同时命题 B \((p \to r) \to (q \to s) = \mathbf{T}\)。

      • 让命题 A 为 False：

        \(X \to Y\) 仅在 True \(\to\) False 时为 False

        根据 \((p \to q) \to (r \to s) = \mathbf{F}\)，有则 \((p \to q) = \mathbf{T}\)，\((r \to s) = \mathbf{F}\)。

        根据 \((r \to s) = \mathbf{F}\)，有 \(r = \text{T}, s = \text{F}\)。

        命题 B 变为：\((p \to \text{T}) \to (q \to \text{F})\)。由于 \((p \to \text{T})\) 必为 True，故命题 B 变为 \(\text T\to (q\to \text F)\)。

      • 让命题 B 为 True：

        则 \((q \to \text{F}) = \mathbf{T}\)，可知 \(q=\text F\)。

        又前面命题 A 为 False 有一个条件是 \((p\to q)=\mathbf T\)，故 \(p=\text F\)。

      综上，当\(p=\text F,q=\text F,r=\text T,s=\text F\) 时，命题 A \((\text{F} \to \text{F}) \to (\text{T} \to \text{F}) = \text{T} \to \text{F} = \mathbf{False}\)，命题 B \((\text{F} \to \text{T}) \to (\text{F} \to \text{F}) = \text{T} \to \text{T} = \mathbf{True}\)，两式真值不一致，故逻辑不等价。

    3. 对偶式 (Dual)

    • 定义：对于仅包含 \(\lor, \land, \neg\) 操作符的复合命题，将其中的 \(\lor\) 替换为 \(\land\)，\(\land\) 替换为 \(\lor\)，\(T\) 替换为 \(F\)，\(F\) 替换为 \(T\)，得到的新命题即为原命题的对偶式，记作 \(S^*\)。
    • 例题：求 \(S = (p \lor \neg q) \land r \lor T\) 的对偶式。
      • 解答：\(S^* = (p \land \neg q) \lor r \land F\)。
    • 定理：如果 \(s\) 和 \(t\) 是两个复合命题，则 \(s \Leftrightarrow t\) 当且仅当 \(s^* \Leftrightarrow t^*\)。

    3. 或非、与非 及 功能完备操作符 (Functionally Complete Operators) 如果仅使用某一小组逻辑操作符就足以等效表达出所有可能的逻辑等价式，则该集合被称为功能完备的。

    • 或非 (NOR / Peirce arrow, \(p \downarrow q\))：当且仅当 \(p\) 和 \(q\) 同为假时为真，即等价于 \(\neg(p \lor q)\)。
    • 与非 (NAND / Sheffer stroke, \(p | q\))：当且仅当 \(p\) 和 \(q\) 同为真时为假，即等价于 \(\neg(p \land q)\)。
    • 常见的完备操作符集合包括：\(\{\neg, \lor\}\), \(\{\neg, \land\}\), \(\{|\}\), \(\{\downarrow\}\)。这意味着在数字电路设计中，仅用“或非”门或“与非”门就能拼出任何复杂的逻辑功能。

    5. 命题可满足性 (Propositional Satisfiability)

    • 定义：如果存在一种对命题变量的真值赋值能使复合命题为真，则是可满足的；如果所有赋值都让它为假，则是不可满足的（矛盾式）。

    • 例题分析：

      1. \((p \lor \neg q) \land (q \lor \neg r) \land (r \lor \neg p)\)：可满足。赋值 \(p=T, q=T, r=T\) 即可。
      2. \((p \lor q \lor r) \land (\neg p \lor \neg q \lor \neg r)\)：可满足。赋值 \(p=T, q=F\) 即可。
      3. 结合上述两式：\((p \lor \neg q) \land \dots \land (\neg p \lor \neg q \lor \neg r)\)：不可满足。尝试所有可能赋值，无一能使其为真。
      4. 应用拓展：可以通过极其庞大的合取命题公式（将规则如每行/列/宫 1-9 不重复等建立约束）对 数独 (Sudoku) 游戏进行编码，并提到了背后的算法复杂性挑战。
      5. 定义命题变量：
        • 设定命题 \(p(i, j, n)\)：表示“在第 \(i\) 行、第 \(j\) 列的格子里，填入的数字是 \(n\)”。
        • 因为有 9 行、9 列以及 9 个候选数字，所以总共会产生 \(9 \times 9 \times 9 = 729\) 个这样的命题。
      6. 建立约束条件：
        • 初始条件：对于题目已经给定的数字，直接断言相应的 \(p(i, j, n)\) 为 True。
        • 行约束（每行必须包含 1-9）：对每一行 \(i\)，对每一个数字 \(n\)，在该行的 9 列中至少有一个格子填了数字 \(n\)。 逻辑表达式为：\(\bigwedge_{i=1}^9 \bigwedge_{n=1}^9 \bigvee_{j=1}^9 p(i,j,n)\)。
        • 列约束（每列必须包含 1-9）：对每一列 \(j\)，对每一个数字 \(n\)，在该列的 9 行中至少有一个格子填了数字 \(n\)。 逻辑表达式为：\(\bigwedge_{j=1}^9 \bigwedge_{n=1}^9 \bigvee_{i=1}^9 p(i,j,n)\)。
        • 宫约束（每个 \(3 \times 3\) 宫格必须包含 1-9）：利用变量 \(r\) 和 \(s\) (\(0\) 到 \(2\)) 来定位 9 个大宫格，保证每个宫格内部必定包含数字 1-9。\(\bigwedge_{r=0}^2\bigwedge_{s=0}^2 \bigwedge_{n=1}^9 \bigvee_{i=1}^3\bigvee_{j=1}^3 p(3r+i,3s+j,n)\)。
        • 唯一性约束（每个格子最多只能填一个数）：如果第 \(i\) 行第 \(j\) 列填了数字 \(n\)，那么它就不能再填任何其他不同的数字 \(n'\)（\(n \neq n'\)）。 逻辑表达式为：\(p(i, j, n) \rightarrow \neg p(i, j, n')\)。
      7. 将上述所有的规则和约束条件用合取符号（\(\land\)，AND）全部串联在一起，这就构成了一个极其庞大的复合逻辑命题。求解数独，本质上就是寻找一种对这 729 个变量的真假赋值（Truth assignment），使得这个庞大的复合命题最终结果为 True。
      8. 如果用穷举真值表的方法去解题，由于有 729 个变量，真值表的行数将达到 \(2^{729}\)，这在现实计算中是完全不可接受的。借此，老师顺带引出了后续会讲到的算法复杂性问题（如 NP 复杂性），指出判断一个命题是否可满足往往是非常困难且耗时的，而验证一个给定的答案是否正确则非常快。

    Section 1.3 (Supplement): 命题范式 (Propositional Normal Forms)¶

    为了让表达式标准化，便于机器识别、符号操作和等价比较，引入了范式理论。

    1. 基础定义

    • 命题公式 (Propositional Formula)：原子变量、真假值、带有逻辑连接符的合法表达式。
    • 文字 (Literal)：一个原子变量或其否定（例如 \(p\), \(\neg p\) 是文字，而 \(p \land q\) 不是）。

    2. 核心范式

    • 命题范式 (Propositional Normal Forms) 的引入是为了将命题公式转换为典型的标准形式，从而更方便地进行机器符号操作，也更容易对两个逻辑公式进行识别和等价比较。

      在命题演算中，主要有两类核心的范式： - 析取范式 (Disjunctive Normal Form, DNF)：由若干个“合取子句（由文字相与构成）”互相

      析取 (\(\lor\)) 组成。

      • 例题：\((p \land q) \lor (p \land \neg q)\)，以及退化的 \(p \lor (q \land r)\) 是 DNF。

      • 合取范式 (Conjunctive Normal Form, CNF)：由若干个“析取子句（由文字相或构成）”互相

      合取 (\(\land\)) 组成。

      • 例题：\(\neg p \land (q \lor \neg r) \land (\neg q \lor r)\) 是 CNF，\(p\land (r\lor (p\land q))\) 不是 CNF。

    • 范式的定义是允许退化的（退化到单个项或单个文字）。例如单个变量 \(p\)、或者单独的 \(\neg p \lor q\)、\(\neg p \land q \land \neg r\)，它们因为没有违反结构规则，所以既属于合取范式，也属于析取范式。

    3. 子句 (Clauses)

    • 在范式整体的三层结构（变量、项、整体拼装）中，括号里构成的每一项被称为子句。利用文字构成的子句具体可以分为两类：

      • 合取子句 (Conjunctive clause)：由文字相互“合取”构成的式子，例如 \(p \land q \land \neg r\)。因为其逻辑结构类似于乘法，所以合取子句也被称为基础乘积 (basic product)。

      • 析取子句 (Disjunctive clause)：由文字相互“析取”构成的式子，例如 \(\neg p \lor q \lor \neg r\)。同理，析取子句也被称为基础加 (basic addition)。

    3. 如何化简为范式

    • 步骤：(1) 消除 \(\rightarrow, \leftrightarrow, |, \downarrow\) 等符号；(2) 利用德摩根定律和双重否定律将 \(\neg\) 向内推进，直到其仅作用于原子变量；(3) 利用分配律和结合律展开（利用 \(p \land (q \lor r) \equiv (p \land q) \lor (p \land r)\)，展开成 DNF 形式；利用 \(p \land (q \lor r) \equiv (p \land q) \lor (p \land r)\)，展开成 CNF 形式）。
    • 例题：将 \(\neg((p \lor \neg q) \land \neg r)\) 转换为合取范式 (CNF)。
      • 推导过程：
        1. \(\equiv\neg(p \lor \neg q) \lor \neg(\neg r)\) (德摩根定律)
        2. \(\equiv\neg(p \lor \neg q) \lor r\) (双重否定律)
        3. \(\equiv(\neg p \land \neg(\neg q)) \lor r\) (德摩根定律)
        4. \(\equiv(\neg p \land q) \lor r\) (双重否定律)
        5. \(\equiv(\neg p \lor r) \land (q \lor r)\) (分配律)
    • 例题：将 \(\neg(p \lor q) \leftrightarrow (p \land q)\) 转换为合取范式 (CNF) 和析取范式 (DNF)。

    • 推导过程：

      1. \(\equiv (\neg(p \lor q) \rightarrow (p \land q)) \land ((p \land q) \rightarrow \neg(p \lor q))\) (消除双条件)
      2. \(\equiv ((p \lor q) \lor (p \land q)) \land (\neg(p \land q) \lor \neg(p \lor q))\) (消除蕴含并推进否定)
      3. \(\equiv ((p \lor q \lor p) \land (p \lor q \lor q)) \land ((\neg p \lor \neg q) \lor (\neg p \land \neg q))\) (分配律等化简左侧、利用德摩根化简右侧)
      4. \(\equiv (p \lor q) \land (\neg p \lor \neg q \lor \neg p) \land (\neg p \lor \neg q \lor \neg q)\) (分配律)
      5. \(\equiv (p \lor q) \land (\neg p \lor \neg q)\) (此即为 CNF 结果)
      6. \(\equiv ((p \lor q) \land \neg p) \lor ((p \lor q) \land \neg q)\) (分配律)
      7. \(\equiv (p \land \neg p) \lor (q \land \neg p) \lor (p \land \neg q) \lor (q \land \neg q)\) (分配律)
      8. \(\equiv (q \land \neg p) \lor (p \land \neg q)\) (此即为 DNF 结果)

    4. 最小项 (Minterm) 与 主析取范式 (Full Disjunctive Form)

    • 最小项定义：包含了所有 \(n\) 个变量的合取（AND），且每个变量恰好出现一次（原变量或其否定）。

    • 编码 (\(m_j\))：按变量的字典序排列，原变量记为 1，否定记为 0，对应的二进制数 \(j\) 即为其下标。

      • 例如：对于变量 \(p, q, r\)，\(m_6\) 对应的二进制为 110，即表达为 \(p \land q \land \neg r\)。

    • 最小项性质：任何两个不同最小项合取必定为 False (\(m_i \land m_k = F\))；所有最小项的析取必定为 True (永真式)。

    • 主析取范式获取方法：

      • 利用真值表法 (From Truth Tables)：对于任何一个布尔函数，在真值表中找出让结果为 True 的所有赋值行，将对应的最小项提取出来用 \(\lor\) 连接即可，\(f=m_j\lor m_k\lor \dots\lor m_l\) 可简记为 \(f = \sum m(j, k, \dots, l)\)。

        • 例题：\(f = (p \land \neg q) \rightarrow (\neg r \land \neg p)\)，列出 \(p, q, r\) 三个变量共 8 行的真值表，计算得出该公式最终结果为 True 的赋值情况共有 6 行：\(FFF\) (\(m_0\)), \(FFT\) (\(m_1\)), \(FTF\) (\(m_2\)), \(FTT\) (\(m_3\)), \(TTF\) (\(m_6\)), \(TTT\) (\(m_7\))。 将这 6 个最小项析取，得到最终结果：\(f = \sum m(0,1,2,3,6,7)\)。

      • 从已有的普通范式补全 (Changing clauses to minterms)：如果已经有了普通的析取范式，可以通过将其中不完整的子句 (clauses) 补齐缺失的变量，从而直接将其转换为主析取范式。

        • 例题： 先用推导法将 \(f = (p \land \neg q) \rightarrow (\neg r \land \neg p)\) 转化为普通析取范式： \(f = \neg(p \land \neg q) \lor (\neg r \land \neg p)\)，\(f = \neg p \lor q \lor (\neg r \land \neg p)\)

          这里的 \(\neg p\) 和 \(q\) 缺少了其它变量。我们利用恒等式 \(x \lor \neg x \equiv T\) 将缺失变量补入： \(f = (\neg p \land T \land T) \lor (q \land T \land T) \lor (\neg r \land \neg p \land T)\) 经过展开，最终同样可以得到由 6 个最小项组成的主析取范式：\(m_0 \lor m_1 \lor m_2 \lor m_3 \lor m_6 \lor m_7\)。

    • 例题：用变量 \(p, q, r\) 构造复合命题，要求当且仅当恰好两个变量为真时，结果为真。

      • 解答：穷举三种为真的最小项（\(m_6\) 即 \(p=T, q=T, r=F\)；\(m_5\) 即 \(p=T, q=F, r=T\)；\(m_3\) 即 \(p=F, q=T, r=T\)），相或得出： \((p \land q \land \neg r) \lor (p \land \neg q \land r) \lor (\neg p \land q \land r)\)。

    • (课程在最后还简要提及了与最小项完全对偶的极大项 Maxterm 及主合取范式，其穷举的是真值表为假的情况)。

    Section 1.3: 命题等价式与命题范式 (补充部分)¶

    4. 命题范式进阶与极大项 (Normal Forms & Maxterms)

    • 极大项 (Maxterm, \(M_j\))：包含了所有变量的析取，是最小项的否定形式（即 \(M_i = \neg m_i\)）。

    • 主析取范式与主合取范式的直接转换：要求一个公式的主合取范式，可以先求出它的主析取范式，然后找出缺失的下标，将这些缺失的下标作为极大项 (\(M_i\)) 的下标，用合取（\(\land\)）符号将它们连起来。

      假设我们有一个包含 \(n\) 个变量的逻辑函数 \(f\)（共有 \(2^n\) 种可能的真值赋值，下标从 \(0\) 到 \(2^n-1\)）。

      1. 已知主析取范式：假设 \(f\) 的主析取范式包含的最小项下标集合为 \(S = {j, k, \dots, l}\)。我们可以将其记为 \(f = \sum m(j, k, \dots, l)\)。
      2. 构造互补函数 \(g\)：我们定义一个函数 \(g\)，让它包含所有在 \(f\) 中没有出现的最小项。也就是提取全集 \(\{0, 1, 2, \dots, 2^n-1\}\) 中剔除 \(S\) 后的剩余下标：\(g = \sum m(\{0, 1, 2, \dots, 2^n-1\} - \{j, k, \dots, l\})\)。
      3. 利用互补性质：由于 \(f\) 和 \(g\) 涵盖了所有可能的互斥真值情况，因此它们相 OR 必定为永真式（\(f \lor g = T\)），相 AND 必定为矛盾式（\(f \land g = F\)）。
      4. 得出否定关系：由上述性质可知，\(f\) 实际上就是 \(g\) 的否定，即 \(f = \neg g\)。
      5. 应用德摩根定律得到极大项：根据德摩根定律，当我们对 \(g\)（一堆最小项的 OR）取否定 \(\neg\) 时，外层的 OR 会全部翻转成 AND，且否定符号会作用到每一个最小项 \(m_i\) 上。
      6. 最终结论：因为 \(\neg m_i = M_i\)（最小项的否定即为极大项），所以 \(f\) 就等于那些未在主析取范式中出现的下标所对应的极大项的合取（乘积）。 记为：\(f=\prod M(\{0, 1, 2, \dots, 2^n-1\} - \{j, k, \dots, l\})\)。

    Section 1.4: 谓词与量词 (Predicates and Quantifiers)¶

    传统的命题逻辑无法表达事物对象、属性及其内部的复杂关系，因此必须引入变量、谓词和量词。

    1. 基础定义

    • 变量 (Variables)：通常用 \(x, y, z\) 表示。
    • 谓词 (Predicates)：如 \(P(x)\)，表示“\(x\) 具有属性 \(P\)”。
    • 命题函数 (Propositional Functions)：带有变量和谓词的陈述（如 \(x+y=z\)）。它本身没有真假值，但当为变量代入具体值或被量词约束时，它就变成了一个可以判断真假的命题。
      • 例题：设 \(R(x, y, z)\) 代表 \(x+y=z\)，论域为整数。求 \(R(2, -1, 5)\) 的真值。
        • 解答：False（因为 2+(-1) = 1，不等于 5）。
    • 论域 (Domain / Universe of discourse)：变量 \(x\) 的所有可能取值范围。

    2. 量词 (Quantifiers)

    • 全称量词 (Universal Quantifier, \(\forall\))：
      • 定义：\(\forall x P(x)\) 表示在论域内，“对于每一个 \(x\)，\(P(x)\) 均为真”。
      • 反例 (Counterexample)：只要在论域中找到一个元素 \(x\) 使 \(P(x)\) 为假，即可证明 \(\forall x P(x)\) 是假的。
      • 例题：设论域为 \({1, 2, 3}\)，\(P(x)\) 为 "\(x < 3\)"。求 \(\forall x P(x)\) 的真值。
        • 解答：False。因为当 \(x=3\) 时，\(3<3\) 是假的，所以存在反例，整体为假。
    • 存在量词 (Existential Quantifier, \(\exists\))：
      • 定义：\(\exists x P(x)\) 表示在论域内，“存在至少一个元素 \(x\) 使得 \(P(x)\) 为真”。
      • 例题：同上论域和属性，求 \(\exists x P(x)\) 的真值。
        • 解答：True。因为只需存在一个即可，例如代入 \(x=1\)，\(1<3\) 为真，命题得证。
    • 唯一性量词 (Uniqueness Quantifier)
      • 定义：\(\exists!x P(x)\) 表示在论域内，“存在且仅存在一个元素 \(x\) 使得 \(P(x)\) 为真”。
      • 等价公式：\(\exists!x P(x) \equiv \exists x (P(x) \land \forall y (P(y) \rightarrow y=x))\)。
        1. 存在性：\(\exists x P(x)\) （至少存在一个 \(x\) 满足条件）。
        2. 唯一性：\(\forall y (P(y) \rightarrow y=x)\) （对于论域中的任意元素 \(y\)，如果 \(y\) 也满足条件 \(P(y)\)，那么这个 \(y\) 必定就是我们找到的那个 \(x\)）。

    3. 量词的性质 (Properties of Quantifiers)

    • 核心规则：包含量词的语句 \(\exists x P(x)\) 和 \(\forall x P(x)\) 的真值，不仅取决于命题函数 \(P(x)\) 本身，还极其依赖于所定义的论域 (Domain \(U\))。同一个命题函数在不同的论域下，真值可能会完全不同。
    • 例题：假设命题函数 \(P(x)\) 为 "\(x < 2\)"。
      • 如果论域 \(U\) 是正整数：\(\exists x P(x)\) 为真（存在 x=1），但 \(\forall x P(x)\) 为假。
      • 如果论域 \(U\) 是负整数：不仅 \(\exists x P(x)\) 为真，\(\forall x P(x)\) 也为真（所有负整数都小于 2）。
    • 这就强调了在使用量词进行逻辑表达和推理时，明确规定论域 \(U\) 是必不可少的步骤。

    4. 量词的优先级 (Precedence of Quantifiers)

    • 核心规则：全称量词 \(\forall\) 和存在量词 \(\exists\) 的优先级高于所有其他的逻辑运算符（如并且 \(\land\)、或者 \(\lor\)、蕴含 \(\rightarrow\) 等）。
    • 易错点与例题：
      • 表达式 \(\forall x P(x) \lor Q(x)\) 实际上等价于 \((\forall x P(x)) \lor Q(x)\)。因为 \(\forall\) 优先级最高，它会率先作用于紧跟其后的 \(P(x)\)，而不会管后面的 \(Q(x)\)。此时 \(Q(x)\) 中的 \(x\) 实际上是没有被量词约束到的。
      • 如果你的本意是想表达“对所有的 \(x\)，\(P(x)\) 或者 \(Q(x)\) 成立”，那么必须加括号，写成 \(\forall x (P(x) \lor Q(x))\)。一定要搞清楚括号该加在哪里的问题。

    5. 绑定变量与自由变量 (Binding Variables)

    在将自然语言或数学语句符号化时，需要了解变量的绑定状态与作用域。

    • 绑定变量 (Bound variable)：如果一个变量被量词（\(\forall\) 或 \(\exists\)）限定了，或者被赋予了一个特定的具体值，它就是绑定的。

    • 自由变量 (Free variable)：既没有被量词约束，也没有被赋予具体值的变量。

    • 命题函数的转变：一个命题函数（如 \(P(x)\)）本身是没有真假可言的，只有当它里面的所有变量都被绑定或赋值后，它才会转变为一个可以判断真假的“命题”。

    • 作用域 (Scope)：量词发挥作用的逻辑表达式片段被称为该量词的作用域。

    • 与编程中“局部变量”类比
      • 例题：在逻辑表达式 \(\exists x (P(x) \land Q(x)) \lor \forall x R(x)\) 中，前半部分作用域里的 \(x\) 和后半部分作用域里的 \(x\) 虽然名字相同，但由于它们分别被不同的量词绑定，所以互不相干，完全是两码事。这等价于 \(\exists x (P(x) \land Q(x)) \lor \forall y R(y)\)。

    6. 英语语句翻译为逻辑表达式 (Translating English to Logic) 翻译时需要特别注意前提约束条件应使用蕴含 (\(\rightarrow\)) 还是合取 (\(\land\))：

    • 例题 1：翻译 “班上每个学生都选修了 Java 课程 (Every student in this class has taken a course in Java)”。

      • 解答 1：如果设定论域 \(U\) 为班上的所有学生，定义 \(J(x)\) 为“\(x\) 选修了 Java”。翻译结果为：\(\forall x J(x)\)。
      • 解答 2：如果设定论域 \(U\) 为世界上所有人，必须新增谓词 \(S(x)\) 表示“\(x\) 是班上的学生”。翻译结果必须使用蕴含：\(\forall x (S(x) \rightarrow J(x))\)。
      • (易错点)：绝不能写成 \(\forall x (S(x) \land J(x))\)，否则意思是“世界上所有人都是班上的学生，并且都选了 Java”。

    • 例题 2：翻译 “班上有些学生选修了 Java 课程 (Some student in this class has taken a course in Java)”。

      • 解答 1：设定论域 \(U\) 为班上学生，翻译为：\(\exists x J(x)\)。
      • 解答 2：设定论域 \(U\) 为世界上所有人，必须使用合取：\(\exists x (S(x) \land J(x))\)。
      • (易错点)：绝不能写成 \(\exists x (S(x) \rightarrow J(x))\)，因为蕴含在遇到不是班上学生的人时自动为 True，导致毫无意义。

    • 回顾苏格拉底的例子 (Returning to the Socrates Example)

    引入了谓词逻辑后，我们终于可以将开篇无法用命题逻辑表达的经典三段论进行符号化表示了：

    • 论域：所有人 (all people)。
    • 前提 1：“所有人终有一死” \(\rightarrow \forall x (Man(x) \rightarrow Mortal(x))\)
    • 前提 2：“苏格拉底是人” \(\rightarrow Man(Socrates)\)
    • 结论：“苏格拉底终有一死” \(\rightarrow Mortal(Socrates)\)

    7. 谓词逻辑中的等价式 (Equivalences in Predicate Logic)

    • 定义：涉及谓词和量词的语句是逻辑等价的，当且仅当无论代入什么谓词，也无论对变量使用什么论域，它们都具有相同的真值。记作 \(S \equiv T\)。

      • 例子：\(\forall x \neg \neg S(x) \equiv \forall x S(x)\)。

    • 涉及量词的核心等价式（注意：前提是变量 \(x\) 没有在命题 \(A\) 中出现过）：

      1. \(\forall x P(x) \lor A \equiv \forall x (P(x) \lor A)\)

      2. \(\forall x P(x) \land A \equiv \forall x (P(x) \land A)\)

      3. \(\exists x P(x) \lor A \equiv \exists x (P(x) \lor A)\)

      4. \(\exists x P(x) \land A \equiv \exists x (P(x) \land A)\)

      5. \(\forall x (A \rightarrow P(x)) \equiv A \rightarrow \forall x P(x)\)

      6. \(\exists x (A \rightarrow P(x)) \equiv A \rightarrow \exists x P(x)\)

      7. (易错) \(\forall x (P(x) \rightarrow A) \equiv \exists x P(x) \rightarrow A\) （注意量词翻转）

        • 推导过程：

          \(\forall x (P(x) \rightarrow A)\) （原式）

          \(\equiv \forall x (\neg P(x) \lor A)\) (利用蕴含等价式 \(p \rightarrow q \equiv \neg p \lor q\)，将条件语句展开)

          \(\equiv (\forall x \neg P(x)) \lor A\) (因为命题 \(A\) 中不包含变量 \(x\)，所以析取项 \(\lor A\) 可以直接提取到量词 \(\forall x\) 的作用域之外)

          \(\equiv \neg (\exists x P(x)) \lor A\) (利用量词的德摩根定律，对谓词的否定等价于翻转量词提取否定符：\(\forall x \neg P(x) \equiv \neg \exists x P(x)\))

          \(\equiv \exists x P(x) \rightarrow A\) (再次反向利用蕴含等价式 \(\neg p \lor q \equiv p \rightarrow q\)，将 \(\neg\) 和 \(\lor\) 组合回 \(\rightarrow\))

          自然语言的直观理解： “对于论域中的每一个 \(x\)，如果 \(P(x)\) 成立则 \(A\) 成立”。这意味着，只要论域中至少存在一个 \(x\) 使得 \(P(x)\) 成立了，结论 \(A\) 就必然会被触发。因此，它等价于“如果存在 \(x\) 使 \(P(x)\) 成立，那么 \(A\) 成立”。

      8. (易错) \(\exists x (P(x) \rightarrow A) \equiv \forall x P(x) \rightarrow A\) （注意量词翻转）

        • 推导过程：

          \(\exists x (P(x) \rightarrow A)\) （原式）

          \(\equiv \exists x (\neg P(x) \lor A)\) (利用蕴含等价式 \(p \rightarrow q \equiv \neg p \lor q\))

          \(\equiv (\exists x \neg P(x)) \lor A\) (同样，因为 \(A\) 中没有 \(x\)，将 \(\lor A\) 提取到作用域之外)

          \(\equiv \neg (\forall x P(x)) \lor A\) (利用量词的德摩根定律：\(\exists x \neg P(x) \equiv \neg \forall x P(x)\))

          \(\equiv \forall x P(x) \rightarrow A\) (反向应用蕴含等价式 \(\neg p \lor q \equiv p \rightarrow q\) 得出结果)

          自然语言的直观理解： “存在某个 \(x\)，使得如果 \(P(x)\) 成立则 \(A\) 成立”。根据蕴含关系的特性，要让 \(P(x) \rightarrow A\) 为真，要么 \(P(x)\) 为假，要么 \(A\) 为真。所以这句话的意思是：存在一个 \(x\) 使 \(P(x)\) 为假，或者结论 \(A\) 直接为真。 反过来看等价式 \(\forall x P(x) \rightarrow A\)：“如果所有的 \(x\) 都使得 \(P(x)\) 为真，那么 \(A\) 为真”。它的等价逆否表达正是：要么不是所有的 \(x\) 都使得 \(P(x)\) 为真（即存在 \(x\) 使得 \(P(x)\) 为假），要么 \(A\) 为真。两者的逻辑内核是完全一致的。

      9. (注：全称和存在量词不能对 \(\rightarrow\) 进行分配。例如 \(\forall x (P(x) \rightarrow Q(x))\) 不等价于 \(\forall x P(x) \rightarrow \forall x Q(x)\))

    8. 量词的属性与德摩根定律

    • 在有限论域下，全称量词等价于所有命题的合取 (\(\land\))；存在量词等价于所有命题的析取 (\(\lor\))。
    • 量词的德摩根定律 (De Morgan's Laws for Quantifiers)：在对量化语句取否定时，需将量词翻转，并将否定符号推入谓词内部。
      • \(\neg \exists x P(x) \equiv \forall x \neg P(x)\)
      • \(\neg \forall x P(x) \equiv \exists x \neg P(x)\)

    Section 1.5: 嵌套量词 (Nested Quantifiers)¶

    1. 定义与概念理解

    • 定义：当一个量词处于另一个量词的辖域（作用域）内时，称这两个量词是嵌套的。例如 \(\forall x \exists y (x+y=0)\)。
    • 计算机视角理解：可以将嵌套量词看作是编程中的多重嵌套循环 (Nested Loops)。外层量词是外循环，内层量词是内循环。必须从外到内按顺序依次考察变量赋值。

    2. 量词的顺序 (Order of Quantifiers) 量词的先后顺序极其重要，直接影响命题的真值：

    • 同类型量词可以自由交换顺序：\(\forall x \forall y P(x, y) \equiv \forall y \forall x P(x, y)\)，以及 \(\exists x \exists y P(x, y) \equiv \exists y \exists x P(x, y)\)。

    • 不同类型量词

      绝不能随意交换顺序：\(\forall x \exists y P(x,y) \not\equiv \exists y \forall x P(x,y)\)。

      • 例题：设论域为实数，\(P(x,y)\) 是表达式 "\(x + y = 0\)"。判断以下两式的真值。
      • 解答 1 (\(\forall x \exists y P(x,y)\))：True。对于每一个给定的实数 \(x\)，我们总能找到一个特殊的 \(y\)（即 \(-x\)）使两者相加为 0。
      • 解答 2 (\(\exists y \forall x P(x,y)\))：False。不存在这样一个“万能”的常数 \(y\)，使得任何实数 \(x\) 加上它都等于 0。

    3. 嵌套量词的翻译 (Translating Nested Quantifiers)

    • 例题：翻译 \(\forall x(C(x) \lor \exists y(C(y) \land F(x,y)))\)。论域为浙大所有学生，\(C(x)\) 为"\(x\) 有电脑"，\(F(x,y)\) 为"\(x\) 和 \(y\) 是朋友"。

      • 解答：浙大的每一个学生，要么自己有电脑，要么他/她有一个拥有电脑的朋友。

    • 翻译 \(\exists x \forall y \forall z (((F(x,y) \land F(x,z) \land (y \neq z)) \rightarrow \neg F(y,z)))\)。

      • 解答：存在一个学生，他/她的所有朋友之间相互都不是朋友。

    • 翻译 “每个人都有且仅有一个最好的朋友”。论域所有人。

      • 解答：为了体现“唯一性”，必须转化为：对于所有人 \(x\)，存在一个人 \(y\) 是 \(x\) 的最好朋友；且对所有人 \(z\)，如果 \(z \neq y\)，那么 \(z\) 就不是 \(x\) 的最好朋友。

        即 \(\forall x \exists y \forall z (B(x,y) \land ((z \neq y) \rightarrow \neg B(x,z)))\)。

    • 使用量词表达极限 \(\lim_{x \to a} f(x) = L\) 的定义。

      • 解答：\(\forall \epsilon > 0 \exists \delta > 0 \forall x (0 < |x - a| < \delta \rightarrow |f(x) - L| < \epsilon)\)。

    • 翻译“两个正整数之和总是正数”。

      • 解答：\(\forall x \forall y ((x>0 \land y>0) \rightarrow (x+y>0))\)。（论域为所有整数）。

    • 翻译“世界上存在一个女人，她乘坐过世界上所有航空公司的航班”。

      • 解答：设 \(P(w,f)\) 为 "\(w\) 乘坐过 \(f\)"，\(Q(f,a)\) 为 "\(f\) 是 \(a\) 航空的航班"。式子：\(\exists w \forall a \exists f (P(w,f) \land Q(f,a))\)。

    4. 受限论域的量词 (Quantifiers with Restricted Domains)

    • 核心转换规则
      • 全称量词 (\(\forall\)) 遇到限制条件时：必须使用蕴含 (\(\rightarrow\)) 来连接限制条件和目标命题。
      • 存在量词 (\(\exists\)) 遇到限制条件时：必须使用合取 (\(\land\)) 来连接限制条件和目标命题。
    • 例题：解释语句 \(\forall x < 0 (x^2 > 0)\) 的含义，并将其转换为标准逻辑表达式。
      • 自然语言含义：对于每一个满足 \(x < 0\) 的实数 \(x\)，都有 \(x^2 > 0\)。
      • 标准逻辑表达式：\(\forall x (x < 0 \rightarrow x^2 > 0)\)。
      • (逻辑解析)：这里如果错误地使用了 \(\land\)（即 \(\forall x (x < 0 \land x^2 > 0)\)），意思就会变成“所有的实数都小于 0 并且平方大于 0”，这显然是荒谬的。使用蕴含 \(\rightarrow\) 则完美表达了“如果它小于 0，那么它的平方大于 0”的条件约束。
    • 例题：解释语句 \(\exists y > 0 (y^2 = 2)\) 的含义，并将其转换为标准逻辑表达式。
      • 自然语言含义：存在一个满足 \(y > 0\) 的实数 \(y\)，使得 \(y^2 = 2\) 成立。
      • 标准逻辑表达式：\(\exists y (y > 0 \land y^2 = 2)\)。
      • (逻辑解析)：这里如果错误地使用了 \(\rightarrow\)（即 \(\exists y (y > 0 \rightarrow y^2 = 2)\)），那么只要在实数中随便找一个负数（比如 \(y = -5\)），前件 \(y > 0\) 就为假，根据蕴含等价式，整个条件语句自动为真，这会导致存在量词得出错误的肯定结论。因此，必须使用 \(\land\) 来确保“既大于 0，平方又等于 2”这两个条件同时被满足。

    5. 否定嵌套量词 (Negating Nested Quantifiers) 法则：连续应用量词的德摩根定律，将最外层的否定符 \(\neg\) 一步步向内部推进，每经过一个量词就将 \(\forall\) 与 \(\exists\) 互换，直到 \(\neg\) 作用于最底层的谓词上。

    • 例题：求 \(\exists w \forall a \exists f (P(w,f) \land Q(f,a))\) 的否定形式。
    • 推导过程：
      1. 原式取否定：\(\neg \exists w \forall a \exists f (P(w,f) \land Q(f,a))\)
      2. 翻转最外层 \(\exists\)：\(\forall w \neg \forall a \exists f (P(w,f) \land Q(f,a))\)
      3. 翻转第二层 \(\forall\)：\(\forall w \exists a \neg \exists f (P(w,f) \land Q(f,a))\)
      4. 翻转最内层 \(\exists\)：\(\forall w \exists a \forall f \neg (P(w,f) \land Q(f,a))\)
        1. 对内部表达式利用命题的德摩根定律展开：\(\forall w \exists a \forall f (\neg P(w,f) \lor \neg Q(f,a))\)。
    • 例题：求 \(\forall x \exists y (xy=1)\) 的否定。
      • 解答：\(\neg (\forall x \exists y (xy=1)) \equiv \exists x (\neg \exists y (xy=1)) \equiv\) \(\exists x \forall y (xy \neq 1)\)。

    6. Some Questions about Quantifiers (关于量词的一些问题)

    1. 能否交换量词的顺序？(Can you switch the order of quantifiers?)

      答案取决于量词的类型是否相同。

      • 问题 A：\(\forall x \forall y P(x, y) \equiv \forall y \forall x P(x, y)\) 是有效的等价式吗？
        • 解答：是 (Yes!)。等式左右两边的真值始终相同。当两个量词都是全称量词（或都是存在量词 \(\exists\)）时，挑选变量 \(x\) 和 \(y\) 的先后顺序完全不影响命题的最终结果。
      • 问题 B：\(\forall x \exists y P(x, y) \equiv \exists y \forall x P(x, y)\) 是有效的等价式吗？
        • 解答：否 (No!)。对于某些命题函数 \(P\)，等式左右两边的真值可能会不同。当不同类型的量词嵌套时，变量被挑选的顺序极其重要。
        • 反例证明：假设论域 \(U\) 为所有整数，命题函数 \(P(x, y)\) 为“\(x + y = 0\)”。
          • 左侧 \(\forall x \exists y P(x, y)\) 的意思是“对每一个整数 \(x\)，都存在一个整数 \(y\) 使得 \(x+y=0\)”。这是真 (True) 的，因为总能找到相反数。
          • 右侧 \(\exists y \forall x P(x, y)\) 的意思是“存在一个特殊的整数 \(y\)，使得对所有的整数 \(x\)，都有 \(x+y=0\)”。这是假 (False) 的，因为不存在这样一个万能的整数。

    2. 量词能否对逻辑连接词进行分配？

      • 问题 A：\(\forall x(P(x) \land Q(x)) \equiv \forall x P(x) \land \forall x Q(x)\) 是有效的等价式吗？
        • 解答：是 (Yes)。全称量词 \(\forall\) 是可以对合取符号（\(\land\)）进行分配的。因为如果“对所有的 \(x\)，\(P\) 和 \(Q\) 都同时成立”，那自然等价于“对所有的 \(x\)，\(P\) 成立，并且对所有的 \(x\)，\(Q\) 也成立”。
      • 问题 B：\(\forall x(P(x) \rightarrow Q(x)) \equiv \forall x P(x) \rightarrow \forall x Q(x)\) 是有效的等价式吗？
        • 解答：否 (No)。全称量词和存在量词绝不能对蕴含符号（\(\rightarrow\)）进行直接分配。
        • 逻辑辨析：左侧代表“对论域里的每一个元素，只要它满足 \(P\)，它就满足 \(Q\)”。而右侧代表“如果论域里的所有元素都满足 \(P\)，那么论域里的所有元素才满足 \(Q\)”。这两句话的逻辑推导条件和涵盖范围是完全不同的，因此不能画等号。

    Section 1.6: 推理规则 (Rules of Inference)¶

    一个论证 (Argument) 是一系列命题的序列，由前提 (premises) 和结论 (conclusion) 组成。如果所有前提的合取蕴含结论是一个永真式，即 \((p_1 \land p_2 \land \dots \land p_n) \rightarrow q\) 是永真式，那么该论证是有效的 (valid)。

    1. 命题逻辑的核心推理规则

    1. 假言推理 (Modus Ponens)：
      • 前提：\(p \rightarrow q\), \(p\) ； 结论：\(\therefore q\)
      • 对应永真式：\((p \land (p \rightarrow q)) \rightarrow q\)
    2. 取拒式 (Modus Tollens)：
      • 前提：\(p \rightarrow q\), \(\neg q\) ； 结论：\(\therefore \neg p\)
    3. 假言三段论 (Hypothetical Syllogism)：
      • 前提：\(p \rightarrow q\), \(q \rightarrow r\) ； 结论：\(\therefore p \rightarrow r\)
    4. 析取三段论 (Disjunctive Syllogism)：
      • 前提：\(p \lor q\), \(\neg p\) ； 结论：\(\therefore q\)
    5. 附加律 (Addition)：
      • 前提：\(p\)；结论：\(\therefore p\lor q\)
    6. 化简律 (Simplification)：
      • 前提：\(p \land q\) ； 结论：\(\therefore p\)
    7. 合取律 (Conjunction)：
      • 前提：\(p\), \(q\) ； 结论：\(\therefore p \land q\)
    8. 消解律 (Resolution)：
      • 前提：\(\neg p \lor r\), \(p \lor q\) ； 结论：\(\therefore q \lor r\)
      • 以通过分类讨论来直观地理解为什么这个推理是绝对成立的
        • 命题 \(p\) 只有两种可能：要么为真（True），要么为假（False）。
        • 情况 1：假设 \(p\) 为假 (False)。 那么为了让前提 2（\(p \lor q\)）成立，既然 \(p\) 指望不上了，\(q\) 就必须为真。
        • 情况 2：假设 \(p\) 为真 (True)。 那么 \(\neg p\) 就为假。为了让前提 1（\(\neg p \lor r\)）成立，既然 \(\neg p\) 指望不上了，\(r\) 就必须为真。
        • 综合结论：既然 \(p\) 非真即假，那么要么 \(q\) 为真，要么 \(r\) 为真。因此，结论 \(q \lor r\) 必然成立。 简单来说，消解律的作用就是把互为否定的项（\(p\) 和 \(\neg p\)）给“消解”（抵消）掉，把剩下的部分用 \(\lor\) 合并在一起。

    2. 构建有效论证 (Valid Arguments)

    • 论证的每一步必须是给定的前提，或者是由前提使用推理规则合法推导出的结果。
    • 例题：已知单个前提 \(p \land (p \rightarrow q)\)，证明结论 \(q\)。
      • 解答：
        1. \(p \land (p \rightarrow q)\) (前提)。
        2. \(p\) (由步骤 1 利用化简律得出)。
        3. \(p \rightarrow q\) (由步骤 1 利用化简律得出)。
        4. \(q\) (由步骤 2 和 3 利用假言推理得出)。

    3. 量化语句的推理规则 (Rules of Inference for Quantified Statements)

    • 全称实例 (Universal Instantiation, UI)：\(\forall xP(x)\)，\(\therefore P(c)\)。

    • 全称引入 (Universal Generalization, UG)：对任意元素 \(c\) 有 \(P(c)\) 成立 \(\therefore \forall x P(x)\)。

    • 存在实例 (Existential Instantiation, EI)：已知 \(\exists x P(x) \therefore\) 必定存在某个特定的元素 \(c\) 使得 \(P(c)\) 成立。
    • 存在引入 (Existential Generalization, EG)：已知特定元素 \(c\) 满足 \(P(c) \therefore \exists x P(x)\)。
    • 全称假言推理 (Universal Modus Ponens)：将全称实例与假言推理结合。已知 \(\forall x(P(x) \rightarrow Q(x))\)，且 \(P(a)\) 成立，\(\therefore Q(a)\)。该规则直接用于解决前文“苏格拉底终有一死”的论证。

    4. 量化语句有效论证综合例题

    • 例题：前提 1: "班上有个学生没读这本书 (\(\exists x(C(x) \land \neg B(x))\))"; 前提 2: "班上所有人都通过了第一次考试 (\(\forall x(C(x) \rightarrow P(x))\))"。证明结论 "有通过考试的人没读这本书 (\(\exists x(P(x) \land \neg B(x))\))"。
    • 解答：
      1. \(\exists x(C(x) \land \neg B(x))\) (前提)。
      2. \(C(a) \land \neg B(a)\) (存在实例 EI)。
      3. \(C(a)\) (化简律)。
      4. \(\forall x(C(x) \rightarrow P(x))\) (前提)。
      5. \(C(a) \rightarrow P(a)\) (全称实例 UI)。
      6. \(P(a)\) (对步骤 3 和 5 使用假言推理 MP)。
      7. \(\neg B(a)\) (对步骤 2使 用化简律)。
      8. \(P(a) \land \neg B(a)\) (对步骤 6 和 7 使用合取律)。
      9. \(\exists x(P(x) \land \neg B(x))\) (存在引入 EG，得证)。

    Section 1.7: 证明导论 (Introduction to Proofs)¶

    1. 基础定义

    • 定理 (Theorem)：可以通过数学推理被证明为真的陈述语句。
    • 公理 (Axioms)：作为推理出发点，被认为是已知为真的基础陈述。
    • 引理 (Lemma)：用于辅助证明定理的“辅助定理”。
    • 推论 (Corollary)：直接从某定理推导出来的结果。
    • 猜想 (Conjecture)：提出来且认为可能为真，但尚未找到证明的陈述。

    2. 证明方法与例题

    • 直接证明法 (Direct Proof)：
      • 例题：证明定理“如果 \(n\) 是一个奇数，那么 \(n^2\) 也是奇数”。
      • 解答：假设 \(n\) 是奇数。则存在整数 \(k\) 使得 \(n = 2k + 1\)。对等式两边平方得到：\(n^2 = (2k + 1)^2 = 4k^2 + 4k + 1 = 2(2k^2 + 2k) + 1\)。令 \(r = 2k^2 + 2k\)，由于 \(r\) 是整数，所以 \(n^2 = 2r + 1\)。这证明了 \(n^2\) 是奇数。
    • 反证法/逆否证明法 (Proof by Contraposition / Indirect Proof)：
      • 例题：证明“如果 \(n\) 是整数且 \(3n + 2\) 是奇数，那么 \(n\) 是奇数”。
      • 解答：假设结论的否定，即假设 \(n\) 是偶数。那么存在整数 \(k\) 使得 \(n = 2k\)。于是 \(3n + 2 = 3(2k) + 2 = 6k + 2 = 2(3k + 1)\)。令 \(j = 3k + 1\)，则 \(3n + 2 = 2j\)。这表明 \(3n + 2\) 是偶数，并非奇数。由于逆否命题得证，故原命题成立。
    • 双条件定理证明 (Biconditional Statements)：
      • 定理形式：\(p \leftrightarrow q\)。必须要分别证明 \(p \rightarrow q\) 和 \(q \rightarrow p\) 两者都为真。

    Section 1.8: 证明方法与策略 (Proof Methods and Strategy)¶

    1. 分情形证明法 (Proof by Cases)

    • 核心逻辑：当证明的条件可以划分成 \((p_1 \lor p_2 \lor \dots \lor p_n) \rightarrow q\) 时，必须将每种情况 \(p_i \rightarrow q\) 都逐一证明。
    • 例题：令操作符 \(@\) 定义为 \(a @ b = \max\{a, b\}\)（即如果 \(a \ge b\) 等于 \(a\)，否则等于 \(b\)）。证明对所有的实数 \(a, b, c\)，结合律 \((a @ b) @ c = a @ (b @ c)\) 成立。
    • 解答：设 \(a, b, c\) 为任意实数，必须且仅有以下 6 种大小关系成立之一：
      1. \(a \ge b \ge c\)
      2. \(a \ge c \ge b\)
      3. \(b \ge a \ge c\)
      4. \(b \ge c \ge a\)
      5. \(c \ge a \ge b\)
      6. \(c \ge b \ge a\) 对 Case 1 (\(a \ge b \ge c\)) 证明：由于 \(a \ge b\)，故 \((a @ b) = a\)；又由于 \(a \ge c\)，故 \(a @ c = a\)。等式右侧：由于 \(b \ge c\)，故 \((b @ c) = b\)；又由于 \(a \ge b\)，故 \(a @ b = a\)。左右两边结果均为 \(a\)，得证。其余5种情况同理可证。

    2. 不失一般性 (Without Loss of Generality, WLOG)

    • 例题：证明如果 \(x\) 和 \(y\) 是整数，且 \(x \cdot y\) 与 \(x+y\) 均为偶数，那么 \(x\) 和 \(y\) 均为偶数。
    • 解答：使用逆否证明法，假设 \(x\) 和 \(y\) 不全为偶数（即至少有一个是奇数）。由于方程对 \(x\) 和 \(y\) 是对称的，我们可以使用短语“不失一般性地 (WLOG)”假设 \(x\) 就是奇数，即 \(x = 2m + 1\)。
      • Case 1：若 \(y\) 是偶数 (\(y = 2n\))，则 \(x + y = 2(m + n) + 1\) 是奇数，不满足原前提。
      • Case 2：若 \(y\) 是奇数 (\(y = 2n + 1\))，则 \(x \cdot y = 2(2mn + m + n) + 1\) 是奇数，亦不满足原前提。由此证得原命题。

    3. 反例证明 (Disproof by Counterexample)

    • 回想等价式：\(\exists x \neg P(x) \equiv \neg \forall x P(x)\)。要推翻全称断言 \(\forall x P(x)\)，只需找出一个令 \(P(c)\) 为假的元素 \(c\)（反例）即可。
    • 例题：“每个正整数都是 3 个整数的平方和”。
    • 解答：结论为 False。反例为数字 7。因为 \(7 = 4 + 1 + 1 + 1 = 2^2 + 1^2 + 1^2 + 1^2\)，它最少需要4个整数的平方和才能构成，故原论断错误。
