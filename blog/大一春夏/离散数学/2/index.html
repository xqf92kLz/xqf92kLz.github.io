    2026-03-222026-03-26

    2026-03-17¶

    Section 2.1: 集合 (Sets)¶

    集合是离散数学中最基础的结构，关系、树、图等高级结构都建立在集合论之上。

    1. 基础概念

    • 定义：集合是无序的元素（对象）组合。集合中的元素“排名不分先后”（无序性），且“重复没有关系”（即使写多次也只算一个元素，如 \(\{a, b, c\} = \{a, b, c, c\}\)）。
    • 表示方法：
      1. 列举法 / 花名册法 (Roster Method)：直接列出，如 \(V = \{a, e, i, o, u\}\)。可以用省略号 ... 表示规律延续，如 \(S = \{1, 2, 3, \dots, 99\}\)。省略号的使用需基于人类常识的共识，理论上带有一定模糊性。
      2. 数学界标准符号：\(\mathbb{N}\)（自然数，含 0）、\(\mathbb{Z}\)（整数）、\(\mathbb{Z}^+\)（正整数）、\(\mathbb{R}\)（实数）、\(\mathbb{Q}\)（有理数）。
      3. 集合构造描述法 (Set Builder Notation)：利用属性规则定义，形式为 \(\{x \mid P(x)\}\)。例如正有理数 \(Q^+ = \{x \in \mathbb{R} \mid \exists p, q \in \mathbb{Z}^+, x = p/q\}\)。
      4. 区间 (Intervals)：如开区间、闭区间。

    2. 特殊集合与悖论

    • 全集 (Universal Set, \(U\))：讨论背景中包含所有元素的集合。
    • 空集 (Empty Set, \(\emptyset\) 或 \(\{\}\))：不含任何元素的集合。
      • 注意：空集 \(\emptyset\) 和 包含空集的集合 \(\{\emptyset\}\) 是不同的。前者基数为 0，后者基数为 1（它包含一个成员：空集本身）。
    • 文氏图 (Venn Diagrams)：用矩形代表全集，圆圈代表集合的图形化表达。
    • 罗素悖论与理发师悖论 (Russell's Paradox & Barber Paradox)：
      • 如果允许集合的任意构造，会导致逻辑黑洞（循环定义）。例如“理发师只给不给自己理发的人理发，那他给自己理发吗？”
      • 在集合论中表述为：设 \(S\) 是所有“不包含自身的集合”组成的集合。问 \(S\) 是否包含自身？无论回答是或否，都会导致自相矛盾。这也是后来公理化集合论诞生的原因之一。本课程采用朴素集合论，避免此类极端构造。

    3. 集合的关系与基数

    • 集合相等 (\(A = B\))：两个集合包含完全一样的成员。逻辑定义为 \(\forall x (x \in A \leftrightarrow x \in B)\)。证明 \(A=B\) 时，通常证明 \(A \subseteq B\) 且 \(B \subseteq A\)。
    • 子集 (Subset, \(\subseteq\))：\(\forall x (x \in A \rightarrow x \in B)\)。因为前提为假时蕴含式必为真，所以空集是任何集合的子集。任何集合也是其自身的子集。
    • 真子集 (Proper Subset, \(\subset\))：\(A \subseteq B\) 且 \(A \neq B\)。
    • 基数 (Cardinality, \(|S|\))：集合中不同元素 (distinct elements) 的个数。例如 \(|\{1, 2, 3\}| = 3\)， \(|\emptyset| = 0\)。
    • 幂集 (Power Set, \(\mathcal{P}(A)\))：集合 \(A\) 的所有子集构成的集合。如果 \(|A| = n\)，则幂集的基数为 \(2^n\)。

    4. 笛卡尔积与有序元组

    • 有序 n 元组 (Ordered n-tuples)：类似于空间坐标 \((a_1, a_2, \dots, a_n)\)，顺序极其重要。二人组称为序偶 (Ordered pairs)。
    • 笛卡尔积 (Cartesian Product, \(A \times B\))：所有可能的有序对 \((a, b)\) 构成的集合，其中 \(a \in A, b \in B\)。大小为 \(|A \times B| = |A| \cdot |B|\)。关系 (Relations) 本质上就是笛卡尔积的子集（如父子关系、付款关系等）。

    Section 2.2: 集合的运算 (Set Operations)¶

    集合的运算与命题逻辑的布尔代数系统是完全一一对应、互通的。

    1. 核心运算

    • 并集 (Union, \(A \cup B\))：对应逻辑的“或者 (\(\lor\))”。
    • 交集 (Intersection, \(A \cap B\))：对应逻辑的“并且 (\(\land\))”。
    • 补集 (Complementation, \(\bar{A}\))：对应逻辑的“否定 (\(\neg\))”。在全集 \(U\) 中但不在 \(A\) 中的元素。
    • 差集 (Difference, \(A - B\))：在 \(A\) 中但不在 \(B\) 中。等于 \(A \cap \bar{B}\)。
    • 对称差 (Symmetric Difference, \(A \oplus B\))：对应逻辑的“异或 (XOR)”。只在 \(A\) 或只在 \(B\) 中出现的元素。等于 \((A - B) \cup (B - A)\)。

    2. 容斥原理 (Inclusion-Exclusion Principle)

    • 特例公式：\(|A \cup B| = |A| + |B| - |A \cap B|\)。两集合基数相加后，需减去被重复计算的交集部分。

    3. 集合恒等式与证明 (Set Identities)

    • 集合恒等式与逻辑等价式长得“一模一样”，包括：恒等律、支配律、幂等律、双重补律、交换律、结合律、分配律、吸收律 等。
    • 德摩根定律 (De Morgan's Laws)：\(\overline{A \cup B} = \bar{A} \cap \bar{B}\)，\(\overline{A \cap B} = \bar{A} \cup \bar{B}\)。
    • 证明集合等价的方法：
      1. 互相证明子集关系：证明左边 \(\subseteq\) 右边，且右边 \(\subseteq\) 左边。
      2. 利用集合的构造描述和命题逻辑的恒等式，一步步用等号推导。
      3. 成员表法 (Membership Tables)：等同于逻辑中的真值表。列出元素 \(x\) 属于各个集合的所有可能情况（例如 3 个集合有 8 种情况）。验证等式两边在所有情况下的从属关系是否完全一致（1 代表属于，0 代表不属于）。由于只需验证这 8 种确定的情形，无需关心集合的具体内容，因此是一种通用的机械证明法。

    4. 计算机中的位串表示 (Bit Strings)

    • 对于有限的全集，人为给它指定一个任意但固定的顺序（排完序后不能再变）。
    • 每个集合就可以用一个二进制位串表示：元素在集合中则该位为 1，不在为 0。
    • 集合的运算完美映射为计算机的逐位逻辑运算 (Bitwise operations)：交集对应 AND，并集对应 OR，对称差对应 XOR。计算极快。

    Section 2.3: 函数 (Functions)¶

    1. 函数的定义

    • 定义：如果 \(A\) 和 \(B\) 是非空集合，函数 \(f: A \rightarrow B\) 是将 \(A\) 中的每一个元素映射到 \(B\) 中的唯一一个元素。可以用笛卡尔积的关系集合来严格定义：每个 \(x \in A\) 在关系对中只能作为起点出现一次。
    • （本课程默认讨论的都是全函数 (Total Function)，即定义域中每一个值都有映射；某些其他数学语境中存在部分函数 (Partial Function)）。
    • 相关术语：
      • 定义域 (Domain)：集合 \(A\)。
      • 陪域 (Codomain)：集合 \(B\)。
      • 像 (Image) / 原像 (Preimage)：若 \(f(a) = b\)，\(b\) 是 \(a\) 的像，\(a\) 是 \(b\) 的原像。
      • 值域/直译 (Range)：函数实际映射到的 \(B\) 中元素的集合（\(B\) 的子集，体现了“实际用到的范围”）。

    2. 单射、满射与双射

    • 单射 / 一对一 (Injection / One-to-one)：不同的输入绝不会映射到同一个输出。即 \(f(x) = f(y) \rightarrow x = y\)。
    • 满射 (Surjection / Onto)：陪域 \(B\) 中的每一个元素都至少被一个 \(A\) 中的元素映射到了。即值域完全等于陪域，\(\forall y \in B, \exists x \in A, f(x)=y\)。
    • 双射 / 一一对应 (Bijection / One-to-one correspondence)：一个函数既是单射，又是满射。它意味着 \(A\) 和 \(B\) 之间存在完美的 1 对 1 映射关系。

    3. 反函数与复合函数

    • 反函数 (\(f^{-1}\))：只有在函数是双射时才存在反函数。例：实数到实数的 \(f(x)=x^2\) 不可逆（既非单射也非满射）；\(f(x)=x+1\) 可逆。
    • 复合函数 (\(f \circ g\))：连续两次映射，即 \((f \circ g)(x) = f(g(x))\)。顺序极度敏感，通常 \(f \circ g \neq g \circ f\)。

    4. 计算机相关特殊函数

    • 上取整 (Ceiling, \(\lceil x \rceil\)) 与 下取整 (Floor, \(\lfloor x \rfloor\))。
      • 定理：整数可以从取整符号中脱离出来，即 \(\lfloor x+n \rfloor = \lfloor x \rfloor + n\) (\(n\) 为整数)。
      • 例题证明：证明 \(\lfloor 2x \rfloor = \lfloor x \rfloor + \lfloor x+0.5 \rfloor\)。
      • 解答思路：利用分情形证明法。设实数 \(x = n + \epsilon\)，其中 \(n\) 为整数，小数部分 \(\epsilon \in [0, 1)\)。由于涉及 \(0.5\)，分为两种情形：\(\epsilon < 0.5\) 和 \(\epsilon \ge 0.5\)。分别代入等式两边进行计算，均能证明两边相等。
    • 阶乘函数 (Factorial, \(n!\))：在算法复杂度中极重要。其增长极快，由斯特林公式知 \(n!\) 与 \(\sqrt{2\pi n}(n/e)^n\) 同阶上升。

    Section 2.4: 序列与求和 (Sequences and Summations)¶

    1. 序列的概念与定义 (Sequences)

    • 序列本质上是自然数（或正整数）集合映射到另一个集合 \(S\) 的函数（常类比为数组）。通过下标 \(a_n\) 表示第 \(n\) 项。

    2. 等差、等比、字符串

    • 等比数列 (Geometric Progression)：\(a, ar, ar^2, \dots\)。其中 \(a\) 被称为初项 (initial term)，\(r\) 被称为公比 (common ratio)。

    • 等差数列 (Arithmetic Progression)：\(a, a+d, a+2d, \dots\)。其中 \(d\) 被称为公差 (common difference)。

    • 字符串 (Strings)：从有限的字符集合（字母表）中提取出来的有限长度的字符序列。

      • 空串 (Empty String)：不包含任何字符的字符串，通常用希腊字母 \(\lambda\) (lambda) 来表示。

    3. 递推关系 (Recurrence Relations)

    • 定义：每一项由前面的项决定。求解必须提供初始条件。
    • 斐波那契数列 (Fibonacci Sequence)：\(F_0=0, F_1=1, F_n = F_{n-1} + F_{n-2}\)。
    • 闭形式公式 (Closed Form)：找出递推关系的非递推代数公式被称为“求解”递推关系。相关的求解方法将会在课程的第 8 章详细讲解。

    3. 求和 (Summations, \(\sum\))

    • 等比数列求和公式推导：求 \(S_n = \sum_{j=0}^n ar^j\)。
      • 推导过程：\(S_n = a + ar + \dots + ar^n\)。将原式乘以 \(r\) 得到 \(rS_n = ar + ar^2 + \dots + ar^{n+1}\)。两式相减可消去中间所有项：\((r-1)S_n = ar^{n+1} - a\)。故当 \(r \neq 1\) 时，\(S_n = \frac{ar^{n+1}-a}{r-1}\)。

    • 复利应用例题：每年末将账户里的钱（本金+利息）取出再全额存入，年利率 11%，求 30 年后 1 万美金本金的终值。

      • 解答：这是一个等比数列应用。\(P_{30} = 10000 \times (1.11)^{30} \approx 228900\)。这展示了指数级（复利）增长的巨大威力。

    • 其他有用的求和公式：

      • 前 \(n\) 个正整数求和：\(\sum_{k=1}^n k = \frac{n(n+1)}{2}\)
      • 平方和：\(\sum_{k=1}^n k^2 = \frac{n(n+1)(2n+1)}{6}\)
      • 立方和：\(\sum_{k=1}^n k^3 = \frac{n^2(n+1)^2}{4}\)

    Section 2.5: 集合的基数 (Set Cardinality) Preliminary¶

    • 基数相等的定义：\(|A| = |B|\) 当且仅当 \(A\) 和 \(B\) 之间可以建立一个完美的双射 (一一对应)。
    • 大小比较：如果存在 \(A\) 到 \(B\) 的单射，则 \(|A| \le |B|\)。如果再确认两集合不相等，则 \(|A| < |B|\)。
    • 可数集合 (Countable Sets)：如果一个无限集合能与正整数集合（或自然数集）建立双射（即能排成一条长队挨个数），那么它是可数的，其基数记为 \(\aleph_0\) (Aleph-null, 阿列夫零)。实数集是不可数的。
    • 无穷的悖论 (思维实验)：
      • 希尔伯特旅馆 (Hilbert's Grand Hotel)：一个有无穷多房间的旅馆已经客满，当新客人到来时，依然能住下。只需让 1 号房间的去 2 号，2 号去 3 号…… 1 号房就腾出来了。
      • 偶数与整数一样多：直觉上正偶数是正整数的子集，数量应该少一半。但只要建立映射 \(f(n) = 2n\)，就能发现正偶数集合与正整数集合能够一一对应。因此它们的基数完全相等（都是 \(\aleph_0\)），这是无穷集合与有限集合截然不同的特性。
    • 施罗德-伯恩斯坦定理 (Schröder-Bernstein Theorem)：若 \(|A| \le |B|\) 且 \(|B| \le |A|\)，则 \(|A| = |B|\)。这大大降低了证明两个无穷集合相等的难度（无需直接构造极难的双射，只需相互构造单射即可）

    Section 2.5: 集合的基数 (Set Cardinality)¶

    1. 基础定义与基数比较

    • 相等 (\(|A| = |B|\))：两个集合基数相等，当且仅当它们之间存在一个双射（一一对应）关系。
    • 小于等于 (\(|A| \le |B|\))：如果存在从集合 \(A\) 到集合 \(B\) 的单射，则说明 \(A\) 的基数小于等于 \(B\) 的基数。
    • 严格小于 (\(|A| < |B|\))：如果 \(|A| \le |B|\) 并且确切知道 \(A\) 和 \(B\) 的基数不相等，则 \(|A| < |B|\)。(注意：无限集合中，不能仅仅因为 A 是 B 的真子集就断定 \(|A| < |B|\))。

    2. 可数集合 (Countable Sets) 与 \(\aleph_0\)

    • 定义：如果一个无限集合能跟正整数集合（或自然数集）建立一一对应（双射）关系，即能够像排队一样用序列排出来，那么它就是可数的。可数无限集合的基数记为 \(\aleph_0\) (Aleph-null, 阿列夫零)。
    • 思维实验（希尔伯特大酒店）：拥有无穷多房间且已客满的酒店，若来了一位新客，只需让 1 号房的去 2 号，2 号去 3 号……即可腾出 1 号房。这展示了无穷可数集合加一后基数不变的特性。
    • 正偶数与全整数：直觉上正偶数是正整数的一半，但它们能建立映射 \(f(n)=2n\) 的双射，因此正偶数集合基数与正整数一样多，皆为 \(\aleph_0\)。同理，所有整数（包括负数和0）也是可数的。
    • 多维坐标点：二维平面上的所有整数坐标点基数也是 \(\aleph_0\)。可以通过从原点出发的“螺旋式”路线将其排队。同理，三维甚至任意有限维度的整数点均为可数。

    3. 伯恩斯坦定理 (Schröder-Bernstein Theorem)

    • 定理内容：如果 \(|A| \le |B|\) 且 \(|B| \le |A|\)，那么必然有 \(|A| = |B|\)。
    • 意义：它极大简化了无穷集合相等基数的证明，无需艰难地构造完美的双射，只需分别构造双向的两个单射即可。

    4. 典型可数集合证明例题

    • 例题 1：证明正有理数集合 \(\mathbb{Q}^+\) 是可数的。
      • 解答：利用伯恩斯坦定理。1) 任何正有理数都可以写成最简分数 \(p/q\) (\(p,q\) 为正整数)，这可以单射到二维正整数坐标点 \((p,q)\) 上。已知二维坐标点集 \(S\) 的基数为 \(\aleph_0\)，故 \(|\mathbb{Q}^+| \le |S|\)。2) 正整数集是正有理数集的一个子集，故 \(|S| \le |\mathbb{Q}^+|\)。两边结合即证得两者基数相等，故正有理数是可数的。
    • 例题 2：由有限字母表构成的有限长度字符串是可数的。
      • 解答：可以将所有字符串按长度（长度0、长度1、长度2...）分组，且每组内部按字典序排列。这样就能不遗漏地把所有字符串排成一列，建立起与自然数的双射。
    • 例题 3：所有可能的 Java 程序是可数的。
      • 解答：Java 程序本质上就是有限长字符串的子集。已知所有字符串可数，可以对其逐一进行编译器检查，丢弃不合法的代码，留下的即为排好队的 Java 程序集合，故为可数。

    5. 不可数集合 (Uncountable Sets) 与 康托尔对角线法

    • 定理：开区间 \((0,1)\) 内的实数集合是不可数的，其基数严格大于 \(\aleph_0\)。
    • 康托尔对角线证明法 (Cantor's Diagonalization)：
      • 证明：使用反证法。假设 \((0,1)\) 内的实数可数，则可以将它们排成序列 \(r_1, r_2, r_3, \dots\)。
      • 我们构造一个新的小数 \(X = 0.x_1 x_2 x_3 \dots\)，构造规则为：让 \(X\) 的第 \(i\) 位小数 \(x_i\) 不同于 第 \(i\) 个实数 \(r_i\) 的第 \(i\) 位（例如，若 \(r_i\) 第 \(i\) 位是 3，则令 \(x_i = 4\)；否则令 \(x_i = 3\)）。
      • 显然 \(X\) 落在 \((0,1)\) 区间内，但它在第 \(i\) 位与序列中的任何一个 \(r_i\) 都不同，说明它不在排好的队列中，产生矛盾。这证明 \((0,1)\) 区间实数不可被排队，即为不可数。
    • 基数等价延伸：
      • 通过双射 \(f(x) = \tan(\pi x - \pi/2)\)，可证 \((0,1)\) 区间的基数与整个实数集 \(\mathbb{R}\) 的基数相等，记为 \(c\) 或 \(\aleph_1\)。
      • 连续统假设 (Continuum Hypothesis)：在 \(\aleph_0\) 和实数基数 \(\aleph_1\) 之间，不存在中间大小的基数。
      • 幂集定理：任何集合的幂集基数严格大于自身基数（\(|P(A)| > |A|\)），说明无穷大没有尽头。
      • 不可计算的函数 (Uncomputable Functions)：由于计算机程序数量是可数的（\(\aleph_0\)），而全体函数的数量是不可数的，因此必然存在大量计算机无法计算的函数。
